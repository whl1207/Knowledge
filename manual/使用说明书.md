## 一、快速开始

### 1.1 软件简介

AI-KM 是一款基于 **Vue3 + Electron** 开发的**桌面端人工智能知识管理平台**。它将「AI 对话、个人知识库、文件管理、RAG 检索、可视化工作流、Agent脚手架与多智能体集群协作、任务看板（待办 / 灵感记录）」整合到一个软件中（技能 / Agent 预设等能力统一在 **设置** 中管理，不再单独占用顶部导航），**所有数据默认保存在本地**，支持离线使用（本地 Ollama / LM Studio 模型）与在线大模型（DeepSeek、OpenAI、Claude、Gemini 等）。

主要能力一览：

| 模块 | 核心能力 |
|---|---|
| 智能推理（主页） | 与 AI 多轮对话，支持普通 / 知识库 / 工作流 / 智能体 / 集群 五种模式（智能体可选 PTC 呈现方式） |
| 知识管理 | 以 Markdown 为核心的个人文件库，支持 11 种视图（浏览/编辑/块编辑/导图/演示/文件/图谱/看板/日历/地图/表格，其中**日历视图内含月视图 / 周视图 / 年视图 / 甘特图**）+ **Excalidraw 白板**、**draw.io 图表**、**工作流画布**（`.flow.yml`）三种文件专属视图；`.kb` 交由**知识处理**打开，`.task` 在独立窗口里用专属**脚手架**视图打开 |
| 知识处理 | 构建 RAG 知识库（切片 → 向量化 → 检索），支持本体图谱与多模式问答 |
| 学习 | 掌握式记忆与复习：总览 / 地图 / 复习 / 错题本 / 考试；掌握度追踪 + 分型间隔复习 + 跳测 + 错因标注 |
| 通用文件 | Markdown / Word / PDF / 图片 / 音视频 / 文本 / Excel / 本地网页，以及 `.excalidraw` 白板与 `.drawio` 图表：在知识管理里打开，可编辑、导出与协同 |
| 工作流文件（`.flow.yml`） | 在知识管理中拖拽连线搭建流程（24 种节点 + 自动创建的**开始 / 结束**骨架节点），一键运行并查看结果 |
| 数据画布（`.data`） | 无代码数据建模：画布节点建模 + 表单录入 + 图表看板；知识管理中的一种文件类型（`.data`），不再是顶层模块，画布内容自动保存到它自己的 `.data` 文件 |
| 技能管理 | 管理**技能**（SKILL.md），已并入设置 → 技能 |
| Agent 预设 | 可复用的 Agent 角色模板，已在设置中管理，主页可一键以其角色对话 |
| 脚手架任务（`.task`） | 知识管理里的一种文件类型：一个 `.task` = 一个独立任务，双击在独立窗口里用专属**脚手架**视图打开（通用执行框架——原批量智能体运行 / 表格定向推理 / 文件采集表格 / 链接采集表格已改为其四种预设） |
| 集群（主页模式） | 多智能体协作：在主页把对话模式切到**集群**，勾选多个 Agent 预设作为成员后发送任务，成员依次作答；支持 @点名、辩论与项目组；成员回复 / 工具调用与其它模式完全同渲染 |
| 浏览器 | 独立窗口的内置浏览器：多标签、收藏书签、离线保存整页，并支持 **AI 直接操作网页**（打开 / 抓取正文 / 填写 / 点击）；见 [九、浏览器](#九浏览器) |
| 插件 | 本地插件：给智能体加工具、往界面加主面板 / 设置页签 / 快捷键，权限按清单声明、未申请的一律拒绝 |
| 内置 MCP 服务 | 六个随软件预置的进程内 MCP 服务：**浏览器 Agent**、**Office 文档（Word + Excel）**、**drawio 图表**、**文献检索（CrossRef / OpenAlex / arXiv / PubMed / Europe PMC）**、**PostgreSQL 只读查询**、**插件开发参考**（共 113 个工具：Office 34 / drawio 44 / 文献检索 9 / PostgreSQL 7 / 浏览器 Agent 13 / 插件开发 6），可被智能体 / 预设 / 集群 / 工作流节点调用，也可对外开放 HTTP 接口（详见 11.5） |
| 设置 | AI 模型配置与上下文窗口、主题、语言、语音、MCP（含 6 个内置服务）、工具与注册表、技能、Agent 预设与日志、协作（共享 / 协同 / 权限：局域网共享 / 共享文件夹 / 协同编辑 / 访客白名单）、Word 导出、文件关联、离线地图等 |

### 1.2 快速上手（新手 5 分钟）

1. **配置 AI 模型**：点击顶部右侧的 ⚙️ 齿轮图标 → 设置 → **模型 → 来源** → 选择 AI 类型（新手推荐本地 **Ollama**，或在线 **DeepSeek**）→ 填写地址 / API Key → 选择模型 → 点**测试连接**看到绿色 **已连接**（点过的来源只是**查看**，要让主页默认用它需再点**设为默认**）。
2. **回到主页聊天**：点击顶部最左侧 🏠 主页图标，在输入框输入问题，按 **Enter** 发送，即可与 AI 对话。
3. **设置知识库目录**（可选）：⚙️ 设置 → **通用 → 基础 → 路径设置 → 工作区**，添加 / 选择你的笔记文件夹。
4. **记录任务 / 灵感**（可选）：顶部 **知识管理** → 左侧面板**视图**勾选 **看板**，点左下角状态栏的 **➕** 打开新建卡片面板，填名称即可（还能顺手选状态与开始 / 结束时间，详见 4.4）。
5. **多人协同编辑**（可选）：在设置 → **协作 → 协同** 中打开**启用协作**并启动协同服务；然后在知识管理中打开一个文件、白板或 draw.io 图表，点协作按钮共享给同一局域网的其他成员，即可**实时协同编辑**（详见 4.6）。
6. **远程文件共享**（可选）：在设置 → **协作 → 共享** 的**共享文件夹**中启动服务并复制链接（`remote-fs://IP:端口?token=…`）；在知识管理文件树空白处右键 →**添加远程工作区**粘贴链接，即可**只读预览**另一台电脑共享的文件夹（PDF / 图片 / Word / 文本，详见 4.7）。
7. **进阶功能**：按本说明书各章节逐步探索知识管理、知识处理、工作流与 Agent 功能。

> 💡 提示：界面支持中英文切换（设置 → **通用 → 基础 → 界面 → 语言**），所有按钮悬停都有提示文字，鼠标放上去即可了解用途。

### 1.4 常见问题（FAQ）

**Q1：聊天时提示未连接怎么办？**
先到 ⚙️ **设置 → 模型 → 来源**，确认 AI 类型与地址 / Key 正确，点 **测试连接**。本地 Ollama / LM Studio 请确认服务已启动；在线模型请确认 API Key 有效。要让主页默认用它，还要再点一次 **设为默认**。

**Q2：知识处理提示未在运行或模型配置错误？**
知识处理跟随全局 AI 配置：请确认当前来源已 **测试连接 / API 状态** 成功、所选模型存在，并已配置**默认嵌入模型**（如 `nomic-embed-text`）。LM Studio 还要求该嵌入模型**已被加载**（或在 Server 里开启 Just-In-Time 加载），否则会报 `No models loaded`。

**Q3：我的数据安全吗？能离线用吗？**
所有对话、知识库与配置默认保存在本地，不会上传到第三方服务器（在线 API 请求除外）；使用本地模型（Ollama / LM Studio）即可完全离线，语音识别也可选本地 ONNX Whisper。

**Q4：新手先学哪个模块？**
建议顺序：**设置**（配模型）→ **智能推理**（聊天）→ **知识管理**（看板记任务 / 建文件）→ **知识处理**（建知识库）→ **学习**（复习掌握）→ 通用文件 / 专属文件 → 插件。

**Q5：PDF 怎么进知识库？**
在知识处理 **文件** 视图，对缺少同名 md 的 PDF 点 **转换** 生成 Markdown，再走切片 → 向量化 → 保存流程。

**Q6：可以在手机上用吗？**
可以。在 **设置 → 协作 → 共享 → 局域网共享** 中启动共享，用手机浏览器访问显示的局域网地址即可聊天（桌面专属的文件浏览 / 设置不可用；访客可用模式与工具见 **协作 → 权限**）。

**Q7：加载知识库后提示检测到未完成的本体构建进度？**
这是**断点续建**机制（与问题提取一致）：未跑完的本体构建**不会自动继续**，需在底部状态栏或 **百科** 页点 **继续** 才恢复。清空本体后按钮应显示 ▶ **开始**；若仍显示**继续**，重进或再清一次即可。

**Q8：为什么有些实体没有关联到切片？**
关联采用**切片文本精确包含实体名**的匹配；模型给出归纳名（规范写法 / 全称）而原文没有原词时，会保留为**孤立概念**而不是丢弃，可在百科 **手动添加实体** 补关联。

## 二、概念介绍

本软件把**模型 + 工具 + 知识**组装成一个能替你干活的助手。看懂下面这几个名词，后面所有章节都会变得很直白——它们大多只是**在设置里的哪一页、在对话里怎么用**的区别。

### 2.1 大模型（LLM）

大模型是软件的**大脑**，负责理解你的话并生成回答。它本身**不绑定在软件里**，而是通过 **设置 → 模型 → 来源** 接入，可选：

- **本地模型**：`Ollama`（推荐）、`LM Studio` —— 完全离线，数据不出本机。
- **在线模型**：`DeepSeek`（默认）、`OpenAI`、`Anthropic`（Claude）、`Google`（Gemini）、`Azure`、`GPUStack`（自托管推理平台）、`自定义`（任何 OpenAI 兼容接口）。

每个来源可以配置**模型、温度、推理强度**（`none` 关闭思考 / `low` / `medium` / `high` / `max`）与**上下文窗口**；对话、知识处理、学习、工作流、Agent 全都**共用这份全局配置**。想换大脑，只改这一处即可。

> 相关章节：设置 → [11.2 模型（Models）](#112-模型models)。

### 2.2 智能体（Agent）

**智能体 = 大模型 + 一套明确的角色设定 + 一组可调用的工具**。普通对话是**你问一句、它答一句**；智能体会自己**规划步骤、调用工具、看结果再决定下一步**，直到把任务做完（例如**读完这个文件夹里的周报，汇总成表格并写回文件**）。

- 智能体的角色由 **Agent 预设**定义（名称 / 系统提示 / 模型 / 工具 / 技能 / 知识库 / MCP），出厂自带八个内置预设（通用 / 代码 / 办公 / PTC / 插件开发 / Pi / DSH / Codex 智能体），也可以自建。
- 在主页聊天里点 👤 选用预设即进入**智能体模式**；同一套预设还能被**工作流智能体节点**、**集群成员**与**脚手架任务**直接复用。

> 相关章节：三、[智能推理](#三智能推理)；设置 → [11.7 智能体（Agent）](#117-智能体agent)。

### 2.3 工具（工具调用）

工具是智能体可以主动调用的能力，例如读写文件、搜索网页、打开网页、执行代码、检索知识库、查数据库等。你不需要手动点，模型会自己决定**什么时候用哪个工具、传什么参数**，再把结果带回来继续推理。

工具来自三处：**内置工具**（随软件提供）、**插件工具**（插件注册的工具）、**MCP 工具**（MCP 服务提供的函数）。前两者的开关与作用域在 **设置 → 工具** 与 **智能体预设 → 工具**；带副作用的工具（写文件、执行命令）会走**审批策略**，可以在设置里选择放行范围。

> 相关章节：设置 → [11.5 工具（Tools）](#115-工具tools)。

### 2.4 程序化工具调用（PTC）

默认情况下模型**逐个**调用工具：调一次、等一次结果、再调下一次。**PTC（Programmatic Tool Calling）**换了一种方式：模型只看到 `run_code` 一个工具，于是它**写一段 TypeScript 程序**，在程序里组合调用本预设启用的那些工具（例如循环处理 20 个文件后再汇总）。

好处是往返次数少、复杂批处理更省 token 也更稳；代价是模型必须在程序里写对调用逻辑。消息里会展示**程序、返回值、console 日志以及程序内调用过的工具**。PTC 只是**模型看到的形态**，不改变能做哪些事——内置的 **PTC 智能体** 预设就是这种形态，任意预设也能在 **设置 → 智能体 → 工具** 把它切成 PTC。

### 2.5 MCP（模型上下文协议）

**MCP（Model Context Protocol）**是接入外部工具能力的通用协议。它把**一堆函数**打包成一个服务，智能体 / 工作流 / 外部客户端都能按同一套方式调用。

- 软件**内置 6 个进程内 MCP 服务**（无需安装）：**浏览器 Agent**、**Office 文档（Word + Excel）**、**drawio 图表**、**文献检索（CrossRef / OpenAlex / arXiv / PubMed / Europe PMC）**、**PostgreSQL 只读查询**、**插件开发参考**，合计 100 多个工具。
- 也可以按需接入**外部 MCP 服务**（填写命令或 URL），或把内置服务**对外开放**给其它程序调用。

> 相关章节：设置 → [11.5 工具（Tools）](#115-工具tools) 的 MCP 小节。

### 2.6 技能（Skill）

**技能是一份怎么写、按什么步骤做的操作手册**：一个文件夹 + 一个 `SKILL.md`（YAML 头描述名称与用途，正文写步骤）。它不提供新工具，而是**教智能体怎么用好已有能力**，因此写起来最轻、复用性最好。

技能可以在聊天里**显式触发**（输入 `$技能名 任务`），也可以让智能体按描述**自动匹配**。

> 相关章节：设置 → [11.6 技能（Skills）](#116-技能skills)。

### 2.7 知识库（`.kb`）与 RAG

**知识库文件（`.kb`）**是把你的文档**切片 → 向量化**之后得到的可检索索引。对话时先检索出最相关的若干切片（**RAG，检索增强生成**），再交给大模型作答——这样回答有依据、可溯源，也不会受模型自身知识边界的限制。

`.kb` 由**知识处理**构建与维护，可被主页的知识库模式、智能体（工具 `kb_search`）、工作流与**学习**模块直接使用。

> 相关章节：五、[知识处理](#五知识处理)；八、[专属文件](#八专属文件)。

### 2.8 插件（Plugin）

**插件是给软件本身增加能力的扩展包**：既能给智能体**加工具**，也能往界面里**加主面板 / 设置页签 / 设置卡片**、注册**全局快捷键**与中英文案。插件用 JSON 清单声明它会申请哪些权限（文件 / 命令 / 网络 / 会话日志 / 大模型），未申请的权限一律拒绝。

插件与宿主同进程运行，请只启用你信任的插件。

> 相关章节：十、[插件](#十插件)。

### 2.9 另外几个常见名词

| 名词 | 一句话解释 |
|---|---|
| **工作流（`.flow.yml`）** | 把**检索 → 判断 → 生成 → 导出**等步骤用节点和连线画出来，一键按固定流程执行；适合重复且步骤明确的活儿 |
| **集群（多智能体协作）** | 主页的一种对话模式：多个 Agent 预设作为成员，同一条任务由他们分工、轮流作答甚至互相辩论 |
| **本体图谱** | 知识处理从文档里抽出的**实体 + 关系**，用于图谱问答与增强检索（配合**学习**模块的知识地图） |
| **脚手架（`.task`）** | 通用 Agent 执行框架：一个 `.task` 文件 = 一个可反复运行的批量任务，内置批量运行 / 表格定向推理 / 文件采集表格 / 链接采集表格四种预设 |
| **数据画布（`.data`）** | 无代码数据建模：画布上定义对象与字段，再用表单录入、图表查看 |

## 三、智能推理（主页 AI 对话）

### 3.1 对话界面总览

主页是整个软件的核心入口，相当于一个功能强大的 AI 聊天助手。

- **聊天列表侧栏**：列出所有对话，每个对话显示模式图标、标题、模型名、消息条数。**默认不显示**，点聊天标题左侧的 **☰（fa-bars）** 按钮展开 / 收起；顶部的搜索 / 新建按钮与每条聊天记录**行高一致（30px）**，并与右侧标题框、下拉框对齐。
- **主聊天区域**：从上到下依次是头部栏（聊天列表开关 / 标题 / 连接状态 / 模型选择）、消息区、输入区。
- **输入卡片**：输入框与下方操作行（对话模式 / 上传 / 语音 / 发送）统一包在一张**圆角矩形卡片**里，卡片内文字输入区与各操作控件**都没有边框**，且**卡片、输入框、下拉框统一用正常背景色**（不用卡片 / 菜单底色，下拉悬浮与展开选项时也不变色）；右侧只保留语音与发送；**生成 / 执行中时最右侧显示停止生成，空闲时显示发送**（同一个位置、互斥）；**有消息时卡片通栏**（不限最大宽度），**空白聊天时收窄居中**（与上方提示同宽）；消息与卡片之间留有间距。
- **状态提示位置**：“正在发送请求 / 正在检索知识库 / 正在思考 / 正在使用 xx 生成回复 / 连接测试 / 其他聊天后台执行中 / 检索统计”等提示在**输入行内、附件按钮右侧**只显示**一个图标**（与附件按钮同尺寸），完整文字在鼠标**悬停提示**里。
- **错误提示**：**系统 / 模型服务返回的错误**（例如“模型服务返回错误 / Context size has been exceeded”）除了在对话里有一条**⚙️ 系统**消息，同一个位置会多出一个**红色感叹号图标**，鼠标悬停可看完整错误，**点一下即关闭**（开始新一轮请求时也会自动清除）。
- **已关联项胶囊**：知识库 / 工作流 / Agent 预设的已选项显示为**模式下拉左侧**的胶囊（点一下可重新选择）。
- **工具卡片（智能体 / 技能执行）**：每次工具调用在回复里穿插一张卡片，默认只显示一行摘要，点右侧箭头展开看完整参数 / 结果；**写入 / 改写的文件都会出现打开按钮**（写入文件 / 替换片段 / 多处替换 / 导出 Word；一次改多个文件时每个文件一个按钮），打开方式与知识管理**完全一致**——应用内独立窗口的对应视图，本地网页（`.html` / `.htm`）用内置浏览器，压缩包 / 可执行文件等交给系统默认应用。
- **空白聊天（还没有任何历史消息）**：头部不显示**输入聊天标题**，卡片在窗口里**垂直居中**、上方给出引导提示（按当前模式给出不同提示）；发送第一条消息时卡片平滑下滑到常规位置，并显示标题输入框。
- **分支面板**：点击头部 🕸 分支按钮后右侧弹出对话分支树。

### 3.2 新建 / 切换 / 删除对话

- **新建对话**：点击侧边栏底部的 **+** 按钮。
- **切换对话**：点击侧边栏中的任意对话。
- **删除对话**：鼠标悬停对话条目，出现 🗑 图标后点击；或右键对话 →**删除聊天**。
- **清空当前对话**：在消息区右键 →**清空聊天**。
- **修改标题**：点击头部栏的标题输入框直接改名，失焦自动保存。

### 3.3 选择模型

头部栏提供两个下拉框：

1. **模型类型**：9 种可选
   - **本地模型**：`ollama`（推荐）、`lmstudio`
   - **在线模型**：`openai`、`deepseek`（默认，可在配置中选择 **Chat Completions**（默认）/ **Responses API** 接口样式，并显示账户余额）、`gpustack`（自托管推理平台）、`anthropic`（Claude）、`google`（Gemini）、`azure`、`custom`（自定义 API）
2. **模型**：点击自动拉取该类型下可用的模型列表并选择。

选好后，点击头部栏的**连接状态圆点**（🟢 绿=在线 / 🔴 红=离线）可以测试模型连接。

> 每个对话**独立记忆**自己的模型配置，切换对话互不影响。

### 3.4 输入框与五种模式（普通 / 知识库 / 工作流 / 智能体 / 集群）

输入框为多行文本框：**Enter 发送，Shift+Enter 换行**。输入框下方有一排模式按钮：

| 按钮 | 模式 | 说明 |
|---|---|---|
| 普通模式 | 默认模式，直接与 AI 交谈；选用支持联网的模型（如 DeepSeek）时提问会自动联网并列出来源 |
| 知识库模式 | 点击后选择 `.kb` 知识库文件，进入**检索 + 回答**模式；可在输入框上方选择**检索策略**（相似度 / 本体 / 多跳 / 社区 / Agentic），并可调**知识库片段数量**（3–20） |
| 工作流模式 | 选择 `.flow.yml` / `.flow.yaml` 工作流文件，按节点执行；编排 / 调试流程也是在知识管理里打开同一份文件（见 8.2） |
| 智能体模式 | 点 👤 选择 Agent 预设，或直接用通用智能体；AI 自主规划并调用工具（读写文件 / 搜索 / 浏览网页 / 执行代码 / 知识库检索 / 技能 / MCP 等），输入 `$技能名` 可显式触发技能。预设的**呈现方式**可设为 **PTC**（程序化工具调用）：模型不逐个调用工具，而是写一段 TypeScript 程序经 `run_code` 组合调用，消息里展示程序、返回值、console 日志与程序内调用的工具（内置**PTC 智能体**预设已是此形态） |
| 集群模式 | 勾选多个 Agent 预设作为成员，一条任务由多成员协作完成（全员响应 / 辩论 / 项目组），可用 `@成员名` 点名 |
| 上传附件 | 图片（≤5MB）或文档（≤20MB：md/docx/pdf/txt/...），内容自动注入给 AI；**智能体模式同样支持上传图片**（多模态，需所选模型支持视觉）；**AI 正在回复时也可以继续上传附件**（不打断当前生成，附件随下一条消息发出）；**也可把文件 / 图片直接拖进聊天窗口**：拖动时窗口中央出现提示浮层，松开即等同点**上传**（知识库模式下拖入 `.kb` 直接关联为知识库）；桌面端与局域网网页端行为一致 |
| 发送 | 发送消息（文字随模式变化） |
| 停止 | 生成中点击中断 |
| 语音输入 | 短按=切换开关，按住说话=松手识别；默认全局快捷键 `Ctrl+Shift+Space` |

**输入框常用技巧**：
- 普通模式下直接输入问题即可。
- 知识库模式：先选 `.kb` 文件，再提问**帮我总结这份文档…**；可在输入框上方切换检索策略（相似度 / 本体 / 多跳 / 社区 / Agentic）。
- 工作流模式：选工作流文件，输入起始文本后执行；执行过程按节点排成可展开的步骤卡片（与智能体模式同款），结束后给出最终输出。
- 智能体模式：输入 `$技能名 任务描述` **显式调用**某个技能，或直接用自然语言描述让 AI **自动匹配**技能。
- 智能体 / 集群执行中：输入框仍可输入，Enter 发送的是**引导**（不打断本轮，下一个 step 生效）；发送图片引导需等本轮结束。
- 需要"写一段程序组合多步工具调用"时（如**把这几份周报里的待办汇总成表格**）：选内置 **PTC 智能体** 预设即可，比逐个工具调用更省往返，程序与程序内调用的工具都会列在消息里；也可在**设置 → 智能体预设 → 工具**把任意预设的呈现方式切成 PTC。PTC 预设同样能进工作流智能体节点、集群成员与批量（脚手架）。

### 3.5 流式输出与停止

- AI 回复**逐字流式**显示，生成中消息区自动滚动到底部。
- 输入区上方显示当前状态：`正在发送请求… / 正在检索知识库… / 正在使用 [模型名] 生成回复…`。
- 点击 **⏹ 停止** 按钮可随时中断生成。
- 联网搜索（DeepSeek 把**接口样式**设为 **Responses API** 时），会显示**正在联网搜索… / 联网搜索到 N 条结果**，回答中的来源链接可点击打开。
- **智能体 / 集群运行中可继续引导**：执行期间输入框不锁死，继续输入要求后按 Enter 即作为**引导**（steer）投递给正在执行的智能体——不打断当前这一轮，智能体在下一个 step 带上这条要求；引导会直接插在智能体正在执行的那条消息的**步骤时间线**里（就出现在它生效的位置，之后生成的步骤排在它下面），运行中发送按钮也会变成 📣 引导。若按下时本轮刚好结束，会提示重新发送，此时按新一轮任务正常发出。

### 3.6 消息右键菜单

在消息上右键（或消息区空白处右键）可：

- **复制文本**：复制选中文字或整条消息
- **朗读文本**：TTS 朗读该消息
- **从此处分支**：从该消息开始创建对话分支
- **清空聊天**
- **导出**：**知识库**（存为 `.md` 到根目录）/ **Markdown**（下载）/ **Word**（下载）

> 单条消息右上角的 `×` 可删除该消息。对话内容自动保存到本地（localStorage 的 `ai-chats`），重启软件不丢失。

### 3.7 特殊内容交互

- **图片**：点击可放大预览并下载。
- **Mermaid 流程图**：AI 回答中的 ` ```mermaid ` 代码块会渲染成图，点击打开模态框，支持**滚轮缩放、拖拽平移、导出 PNG / SVG、重置**。
- **代码块**：自动语法高亮。
- **数学公式**：支持 `$...$` 行内公式和 `$$...$$` 块级公式（MathJax）。
- **知识库来源**：知识库模式回答底部显示**参考了 N 个知识片段**，点击可展开每个片段的来源与相似度。
- **Token 统计**：助理消息右上角显示输出 token 数与速度。

### 3.8 上下文占用圆环

聊天标题右侧的**圆环**显示当前对话的上下文占用率（参考 DeepSeek Harness 的做法）：

- **已用（分子）**：优先取模型返回的**真实 `promptTokens`**；后端不回传用量时按与实际请求一致的口径**估算**，悬停提示里会标注**（估算）**。估算口径与请求一致：**工具结果（读取到的文件正文）、工具参数（写入的文件正文）、知识库召回片段、附图、固定开销（系统 prompt + 工具 schema + 会话种子）都计入**，并按**来源 + 模型**记住的**实测校准系数**修正（本地 Ollama / LM Studio 的 tokenizer 与估算口径差异可达 15%~30%，不校准会系统性低估、压缩来不及生效）。
- **上限（分母）**：优先级 = 来源级手填 > 后端真实探测（Ollama / LM Studio 可读到已加载实例的真实窗口，例如本地手动设成 64K 也能被读到）> 模型名关键字 > 来源默认值 > 128K。可在 **设置 → 模型 → 来源** 每个来源配置块底部的**上下文窗口**只读行查看当前分母；在该块底部的**API 状态**点一次即可强制重新探测。
- **颜色**：低于 70% 为主题色、70–90% 橙色、≥ 90% 红色（提示该新建对话了）。
- **自动压缩（重要）**：占用达到上限的 **80%** 时，较早的对话会被自动压成一份**结构化摘要**（保留最近 3 轮原文逐字不动）：
  - 摘要随会话保存，可在 **设置 → 日志** 查看；**聊天里的原始消息一条都不会删**，只是不再随请求发出；
  - 摘要由当前模型生成；若摘要不可用（离线 / 报错）则退化为**关键信息索引**，保证不会因超限中断；
  - 若模型后端直接报**上下文超限**，会自动压缩并**重试一次**；本地 Ollama / LM Studio 以往从 prompt 头部静默截断（表现为**失忆**）的情况也一并避免。
  - **压缩有提示**：智能体模式会在对话里显示**正在压缩上下文…**，完成后该卡片变为**已压缩较早对话（原消息仍保留）**并弹一条提示；普通聊天则在压缩重试时弹出提示。
- 集群模式不显示圆环（每个成员各有独立上下文，合并数值没有意义）。

### 3.9 集群模式（多智能体协作）

**集群**是**主页的一种对话模式**：把主页输入区的模式下拉切到**集群**，就能让**多个智能体参与同一条对话**——发送任务后成员依次作答，也可以 `@成员名` 只点名某一位。

> 💡 与旧版的区别：集群不再有独立的模块、预案文件（`.swarm`）与关系图谱。**成员就是 Agent 预设**（在**设置 → 智能体 → 预设**中维护），改预设即改成员；对话里只记录“选了哪几个预设”。成员汇报、工具调用、推理过程都作为**普通消息**留在该对话中，渲染与其它模式**完全一致**。
> 运行中，聊天列表里该对话会显示**转圈图标**（悬停提示**集群运行中...**）并高亮边框，与智能体运行时一致；切到别的对话也不会漏看。

#### 3.9.1 准备成员（Agent 预设）

集群成员来自**设置 → 智能体 → 预设**：每个预设包含角色系统提示、模型、温度与能力（工具 / 技能 / 知识库 / MCP）。集群不需要也不允许在对话里单独改成员配置——要调成员就在预设里调，所有使用该预设的对话同步生效。

#### 3.9.2 在主页开启集群模式

1. 主页输入区左下角**模式下拉** → 选择**集群**。
2. 旁边出现**成员标签**（`成员 N` / `选择成员...`）：点击弹出预设列表，**勾选**参与本次任务的成员；**勾选顺序 = 发言顺序**。浮层底部**管理预设...**可直接跳到预设设置页。
3. 若某个预设被删除或改名，成员标签会以橙色提示**清理已失效引用 N**，点一下即可移除这些无效引用。

#### 3.9.3 运行方式

成员标签右侧是**运行方式**下拉（随对话保存）：

| 运行方式 | 说明 |
|---|---|
| **🤖 全员响应（默认）** | 所有选中成员依次就任务作答；成员也可在回复里 `@同事` 追加协作 |
| **🗣️ 辩论** | 多个成员围绕任务**多轮辩论**，最后由群主中立总结，适合需要多方对比的决策类问题 |
| **🧭 项目组（Lead 编排）** | 由第一位成员担任 Lead，自动把目标拆成任务、按依赖指派成员并汇总交付；消息与工作台（泳道 / 名册 / 任务 / 通信）为**并列标签**、各自全宽；泳道按依赖层级竖向展示任务关系与成员状态；名册显示 token / 工具次数 / 最后活动（超 90 秒无活动就提示可能卡住）；停止后可在任务页**继续未完成任务**；任务页可调并发闸门（1~8），点任务跳转对应消息、点消息上的任务标签回到任务板；长产出用**产出物**落成文件（群聊显示可打开的卡片，任务卡带 📎 附件），不占上下文 |

- **前文注入**默认开启：发送任务时会带上该对话此前的成员汇报，成员能看到上下文。
- **项目组**使用独立消息栏：顶部只有一行（左侧：聊天列表开关 + 聊天名称；右侧：工作台标签），协议事件（加入 / 任务变更 / 停止）折叠为细条、成员间通信显示为通信条，底部发送栏与其它模式共用。

#### 3.9.4 发送任务与 @点名

在输入框输入任务，回车 / Ctrl+Enter 发送：

- **不带 `@`**：按运行方式让成员参与。
- **带 `@成员名`**：**只唤起该成员**单独执行。适合先让某位成员处理，或对某个结果追问。

#### 3.9.5 查看过程与结果

- 成员汇报就是对话里的消息：正文按 Markdown 渲染；**工具调用与思考过程以卡片内联在消息中**（与智能体模式完全一致），点击可展开查看参数与结果。
- 消息头会显示发言成员名；**参考了 N 个知识片段**、token 用量、执行耗时等统计也与其它模式一致。
- 运行中可点 **■ 停止**；任务完成后会自动生成对话标题。
- 对话本身支持持久化、分支、搜索、导出，与普通对话无异。

> 💡 **新手建议**：先在**设置 → 智能体 → 预设**准备 2–3 个职责不同的成员（例如“资料检索员”“数据分析员”“审稿人”），然后在主页切到集群模式勾选它们、直接发送任务即可；想精确指定某人先做就用 `@成员名`。

## 四、知识管理（文件与协作）

知识管理是软件的文件中心，以 **Markdown 为核心**，管理你的本地知识库。

### 4.1 第一步：设置知识库根目录

1. 点击左侧目录树顶部的 📂 **打开文件夹** 按钮（或右键空白处 → 添加本地工作区）。
2. 在系统弹窗中选择你的笔记文件夹，即成为**知识库根目录**，目录树自动加载，并实时监听文件变化自动刷新。

> 根目录会持久保存，下次启动自动恢复。也可以点 📄 **打开文件** 打开库外的单个文件。

### 4.2 文件基本操作

| 操作 | 方法 |
|---|---|
| **新建文件夹** | 目录树空白处 / 文件夹上右键 → 新建 → 文件夹（在文件夹上右键则建在它里面） |
| **新建文件** | 目录树顶部 ➕ 按钮；或在目录树空白处 / 文件夹上右键 → 新建 → Markdown / Excalidraw 白板 / draw.io 图表 / 工作流 `.flow.yml` / 数据画布 `.data` / 脚手架 `.task` |
| **重命名** | 右键 → 重命名（看板卡片也可在卡片上右键 → 重命名） |
| **删除** | 右键 → 删除（有确认提示，删除文件夹会递归删除） |
| **复制 / 粘贴** | 右键文件或文件夹 → 复制（在**重命名**下方），再到目标文件夹（或文件 / 空白处）右键 → 粘贴（同目录重名会自动加**_副本**）；剪贴板与**文件**视图共用 |
| **移动** | 在目录树中**直接拖拽文件**到目标文件夹（只有文件可拖，文件夹不可拖） |
| **打开文件所在位置 / 复制地址** | 右键 → 打开文件所在位置（在系统文件管理器中定位）、复制地址（复制完整路径）、系统打开（交给系统默认应用）；文件右键时这三项在**操作**子菜单里 |
| **排序** | 右键 → 排序 → 按名称 / 修改时间 / 大小 / 类型（再次点击切换升降序） |

> **新建的文件放在哪**：**右键某个文件夹**时建在它里面，否则一律建在**当前文件夹**（顶部面包屑所指目录，也就是各视图正在浏览的目录；想建在别处先用文件树双击 / 面包屑切过去）。看板左下角状态栏 **➕** 新建的卡片同理，落在当前文件夹里。

### 4.3 打开与预览文件

**双击**目录树节点或文件列表项即可打开（一律在**独立窗口**打开，可同时开多个并排对照）。独立窗口的标题栏显示**文件名 - 视图**，**鼠标悬停在文件名上会显示文件的绝对路径**；没有正文的 Markdown（空文件，或只有 YAML 头、如看板新建的卡片）会**默认打开源码编辑**而不是空白的浏览视图。**双击文件夹**则只让右侧当前视图（文件 / 看板 / 表格 / 图谱 / 地图 / 日历）定位到该目录（多工作区时，若该文件夹属于别的工作区，会先把那个工作区切为当前工作区再定位）。目录树的**展开 / 折叠点节点左侧的箭头**（单击不再开合节点，避免双击时先开后收）。支持的文件类型：

| 类型 | 预览方式 |
|---|---|
| Markdown（`.md` / `.kb`） | 完整渲染：数学公式、Mermaid 图（可点开放大/导出）、**内嵌 draw.io 图表**（`![](图.drawio)`，浏览 / 可视编辑 / 导图 / 演示四个视图都会渲染，多页逐页渲染、`#page=2` 指定页，点哪一页就打开哪一页）、代码高亮、目录树、**一键运行 Python 代码块**、TTS 朗读、**导出 Word**（含图表） |
| Word（`.docx`） | 自动转 Markdown 渲染，可导出为 Markdown |
| PDF | 逐页浏览、滚轮缩放、拖拽平移、**OCR 识别**（需本机 Ollama 模型）、**右键 / 图标翻译**（译文原地叠加） |
| 图片 / 视频 / 文本 | 图片缩放查看、视频播放、纯文本直接显示 |
| Excel（`.xlsx`） | 转 Markdown 表格显示 |
| 网页（`.html` / `.htm`） | 默认用**内置浏览器**打开渲染（可继续用 AI 操作 / 提取正文）；要看文件视图预览或改源码，用右键 → 打开 → 选对应视图 |
| draw.io（`.drawio` / `.dio`） | 内嵌 draw.io 编辑器直接绘制（离线可用，含 AI 智能操作），见 7.4 |
| 工作流（`.flow.yml` / `.flow.yaml`） | 内嵌工作流编辑器直接编辑（浏览 / 可视编辑视图），源码编辑视图显示 YAML 文本，见 8.2 |
| 数据画布（`.data`） | 内嵌数据画布模块（浏览 / 可视编辑视图），源码编辑视图显示 JSON 文本，见 8.4 |

> **浏览视图的进阶能力（Markdown / Word / 纯文本）**：底部状态栏最右侧的 ✨ **智能操作** 图标可与**当前文档智能对话**（提问前可勾选附带**整篇（默认）/ 当前章节 / 选中文字**，上限约 12 万字符，超出会明确提示已截断）；再往左的 ⬇ **导出文档** 图标菜单里有**导出 Markdown / 导出 Word / 导出 PDF**，其中**导出 Markdown** 与**导出 Word** 都会弹出另存为对话框（默认当前文件所在目录，Word 另有导出样式：公文 / 中文论文 / 英文论文 / 自定义 `.docx`，公式优先转为 Word 原生可编辑公式），导出后提示实际保存路径。PDF 的转换面板同样提供**智能操作（与 PDF 对话）**。
>
> **PDF 翻译**：在 PDF 里**选中文字后右键 →翻译**，译文按段落**原地叠在原文字位置**上（不会盖住旁边的栏或单元格）；也可以点右下角的 **🌐 翻译图标**叠加中文译文，**滚动 / 翻页到的页会自动继续翻译**（整份文档要么每页都叠加、要么都不叠加，不会出现半英半中），再点一次整份切回原文。右键该图标可指定翻译用的来源与模型（默认跟随**系统默认来源**的模型，无需额外配置），弹层里还有**清空译文缓存**按钮。译文里的公式会自动按 LaTeX 用 KaTeX 渲染（行内公式与正文同段、展示公式居中），以公式 / 数字为主的碎片直接跳过；原文的段首缩进与列表悬挂缩进会一并还原，译文较短时自动放开行距并上下居中填满原段落范围。译文语言跟随系统语言（中文界面→简体中文，英文界面→English）；同一份文档、同一目标语言与模型下的译文会缓存在本地，翻页回来或重新打开不再重复请求。

### 4.4 视图与文件类型（简述）

知识管理用**视图**来呈现同一批文件：顶部工具栏的**视图选择**下拉可在**文件 / 图谱 / 看板 / 日历 / 地图 / 表格**六个全局视图间切换（右侧一次只显示一个；默认视图可在 **设置 → 功能 → 知识管理** 里改），加上打开文件后的**浏览 / 源码编辑 / 可视编辑 / 思维导图 / 演示**，通用视图共 **11 种**——每种视图的详细说明见 [七、通用文件](#七通用文件) 的 **通用视图** 小节。

文件本身分两类，各有各的打开方式（详细说明见 [七、通用文件](#七通用文件) 与 [八、专属文件](#八专属文件)）：

| 类型 | 是些什么 | 到哪里看 |
|---|---|---|
| **通用文件** | Markdown、Word、PDF、图片 / 音视频、纯文本、Excel、网页，以及 `.excalidraw` 白板与 `.drawio` 图表 | [七、通用文件](#七通用文件) |
| **专属文件** | `.kb` 知识库、`.flow.yml` 工作流、`.task` Agent脚手架任务、`.data` 数据画布 | [八、专属文件](#八专属文件) |

> **看板 / 日历 / 表格** 这三个视图都基于 Markdown 的 **YAML 属性（frontmatter）**，因此任务、日程、资料表都可以只是普通 `.md` 文件——这就是本软件所说的**文件优先**。

### 4.5 搜索

- **目录树过滤**：目录树顶部搜索框，实时按文件名过滤。
- **全文搜索**：点击顶部 🔍 搜索按钮进入搜索模式，输入关键词（多个词用空格分隔），自动搜索整个知识库（匹配文件名 + `.md` 内容），结果双击打开——按设置 →**文件操作**的方式打开（**新窗口**开独立窗口 / **窗口内**开主窗口标签页，与点击文件树一致）；打开后搜索面板**保持打开**，可连续打开多个结果，按 `Esc` 或点右上角 ✕ 关闭。

### 4.6 局域网协同编辑（重点）

在**同一局域网**内，多台电脑可以**实时协同编辑**同一个文件——支持 **代码 / Markdown 编辑器**、**Excalidraw 白板**与 **draw.io 图表**三种场景。基于 **Yjs CRDT** 与增量补丁（draw.io 用官方 diffSync）实现元素级实时同步：一边编辑、另一边立即可见，并显示**成员光标、名称徽标**与成员列表。

#### 4.6.1 开启协作

1. 进入 **设置 → 协作 → 协同**。
2. 打开**启用协作**开关，点击**启动协同服务**。
3. 可配置：**端口**（默认 `3346`）、**最大成员数**、**编辑权限**、**房间 Token**、**自动保存间隔**、**客户端名称**。

#### 4.6.2 共享文件 / 白板 / 图表

- **代码编辑器**：在编辑器底部状态栏点击协作图标（👥）→**共享此文件**，生成加入地址。
- **Excalidraw 白板**：点白板**右下角**的**协作按钮** →**共享此白板**。
- **draw.io 图表**：点图表**右下角**的**协作按钮** →**共享此图表**（未在设置中启用协作时该按钮不显示）。
- 加入地址形如 `ws://IP:端口/collab/房间号?token=…`，复制发给局域网内其他成员即可。

#### 4.6.3 加入会话

- 其他成员打开同一文件，点击协作按钮 →**加入会话**，粘贴地址并填写**昵称**即可加入。
- 加入后即可**实时看到彼此的光标、名称徽标与编辑内容**，并支持**同步主机的视图位置与缩放**。
- 协作者可被授予**主机 / 可编辑 / 只读**角色；只读成员可点**请求编辑权**由主机批准（权限模式为**批准**时）。

#### 4.6.4 权限与保存

| 权限模式 | 说明 |
|---|---|
| **开放**（默认） | 全员可编辑 |
| **批准** | 只读成员可请求编辑权，由主机批准 |
| **只读** | 仅主机可编辑 |

- **仅主机可保存到磁盘**（自动保存间隔可在设置中配置）；成员退出不丢失已同步内容。
- 白板支持图片等嵌入内容实时同步；代码编辑器支持成员光标与选区高亮。
- **draw.io 图表**走官方**增量同步（diffSync）**：每次编辑只广播变更补丁，各方画布即时更新且不会相互覆盖；新成员加入时由主机现导一份权威图表内容作为同步基准，因此会话中**只有主机可写盘**、也只有主机能发起 AI 智能操作。图表协同**不显示他人光标位置**。

> ⚠️ 协作需要所有成员处于同一局域网并能互通端口；首次使用请先在设置中启动协同服务。

### 4.7 远程文件共享（共享文件夹 · 只读预览）

通过**共享文件夹**，可以把本机的一个文件夹**只读共享**给局域网内的其他电脑：对方在**知识管理 → 文件树**中添加为**远程工作区**（☁️ 云图标，恒显示在所有本地工作区最下方），即可浏览、**预览**其中的文件——支持 **Markdown / 文本 / PDF / 图片 / Word**，下载后即可编辑。

#### 4.7.1 主机端共享

1. 进入 **设置 → 协作 → 共享 → 共享文件夹**。
2. 启动**共享文件夹服务**，选择要共享的目录，配置端口（默认 `3347`）与 Token。
3. 复制连接地址（`remote-fs://IP:端口?token=…`）发给局域网内的其他成员。

#### 4.7.2 客户端添加远程工作区

- 在**知识管理 → 文件树空白处右键 → 添加远程工作区**。
- 粘贴上面的连接地址（或分别填写主机、端口、Token），共享目录即合并进文件树（☁️ 云图标、恒在最下方），可**懒加载**浏览目录与文件（点击目录时才拉取子级）。

#### 4.7.3 预览与下载

- 远程文件为**只读预览**：Markdown / 文本直接阅读，**PDF / 图片 / Word** 在**浏览**视图内联预览。
  - **PDF**：完整翻页 / 缩放 / OCR / 翻译。
  - **图片**：缩放 / 拖拽 / OCR。
  - **Word（.docx）**：自动转 Markdown 渲染（旧版 `.doc` 不支持，需下载）。
- 需要编辑时，点击顶部提示条的**下载到本地**，文件保存到当前工作区后即可正常编辑。

#### 4.7.4 刷新远程目录

- 每个远程工作区根节点**最右侧有一个刷新按钮**（🔄），点击后重新拉取服务端目录，及时看到主机端新增 / 修改 / 删除的文件变化。
- 右键远程节点可**预览 / 下载到本地工作区 / 删除远程工作区**；删除远程工作区不影响主机文件。

> ⚠️ 远程文件为**只读**，修改请先下载到本地工作区；主机端需保持共享服务运行，且各客户端处于同一局域网、能访问端口 3347。

## 五、知识处理（RAG 知识库构建）

知识处理模块用于把文档**构建成可检索的 AI 知识库（RAG）**。本模块**跟随全局 AI 配置**（设置 → 模型 → 来源中选择的 AI 来源与模型，支持 Ollama / LM Studio / OpenAI / DeepSeek（Chat / Responses 接口样式）/ GPUStack / Anthropic / Google / Azure / 自定义来源），无需在知识库内单独配置来源。

顶部有八个标签页：**问答 / 文件 / 切片 / 问题 / 百科 / 本体 / 测试 / 设置**。右上角是知识库工具栏：当前文件夹路径、版本下拉框、📂 打开文件夹、⬇ 读取知识库、💾 保存知识库。

### 5.1 按顶部导航逐页使用（推荐阅读顺序）

知识处理把“文档 → 可问答的知识库”拆成了 8 个标签页，建议按下面的顺序走一遍；每个标签的进阶细节见后文对应小节。

**① 问答标签页（主页面）**
- 顶部下拉选择**检索策略**（默认内置 相似度 / 文件增强 / 问题增强 / 本体增强 / 多跳 / 社区 / Agentic 等，可在**设置**中自定义）；右侧可调 片段数量、阈值 等。
- 输入问题回车即可；回答右侧的**佐证面板**展示引用的切片/来源。
- 若知识库还没切片 / 向量化，直接提问会自动完成准备再检索；也可先到**切片**页手动处理。

**② 文件标签页（选库与转换）**
- 📂 打开文件夹选择知识库根目录；右上角可**读取 .kb**（版本下拉切换）与 **保存 .kb**。
- 左侧列出 Markdown / PDF / Word；PDF/Word 缺同名 `.md` 时，点顶部 ✨ **转换** 一键生成同名 Markdown。
- 增量更新检测到**新增 / 修改 / 删除**时，文件名标色 + 徽标提示。
- 左栏顶部会列出**缺失文件**：知识库记录、但当前文件夹里已没有的文件（按同名匹配，容忍文件夹改名 / 移动）。点 🗑 可清理这些文件的**切片 / 问题 / 摘要**（需确认）；**保存 .kb 时不会自动删除**，只在提示里告知。

**③ 切片标签页（切分与向量化）**
- 选**切片策略**（默认 / 智能 / 语义）→ 点 ✂ **剪刀** 切分文档；再点 🧲 **磁铁** 为切片生成向量。
- 支持 Ctrl+滚轮缩放卡片、点击卡片定位；随时可点 🔄 **增量更新** 同步文件变更（本体 / 摘要 / 社区会一并增量）。

**④ 问题标签页（问题库）**
- ▶ **提取问题**：为切片生成“问题 + 答案”对（支持暂停 / 继续 / 停止，进度在底部状态栏）；下方蓝色行为该题独立答案。
- ⚡ **提取时立即向量化**（默认关）：关闭时先连续推理，**全部结束后统一补一次问题向量** —— LM Studio 等单服务下对话 / 嵌入模型不能同时常驻，边推理边嵌入会每条都换载模型、非常慢；显存充足想即时向量化时再打开。
- 可**手动添加 / 去重合并 / Excel 导入导出 / 生成复合问题**；⚖ **独立性评审**可让大模型标出“不能独立作答”的问题（标红、仅会话内不保存，计数在状态栏）。
- 🗑 **清空全部问题**：删除问题库中所有问题（需确认）；**切片与文件不受影响**，测试页由问题库派生的用例会一并清空（外部导入的独立用例保留）。提取正在进行时需先「停止提取」。
- 列表**每 40 条下滑加载**；问题文本在左、来源/操作在右，悬停问题可看所在文件。测试题的来源即本页问题库。

**⑤ 百科标签页（构建与卡片）**
- ▶ **开始抽取实体**＝启动本体构建（从切片抽实体/关系/描述），运行中可暂停 / 停止，**进度只在底部状态栏**。
- 带断点的库只显示 ↻ **继续**（从断点恢复，不自动跑）；🗑 **清空** 会删除全部实体（即卡片）与关系（需确认）。
- 卡片网格里可 ➕ 手动添加实体、批量生成描述、搜索。

**⑥ 本体标签页（图谱）**
- D3 力导向图谱查看实体 / 关系 / 切片 / 文件 / 问题节点（右上角开关显示各类节点与关联线）。
- ⛓ **手动连线**：点连线按钮进入模式，依次点两个**概念节点**，由大模型判定关系类型（提示在底部状态栏）。
- 可运行**社区检测 / 生成报告**，按社区筛选图谱。
- **生成报告**（社区报告的 LLM 推理）支持**暂停 / 继续 / 停止**：推理中按钮变为 ⏸，暂停后用 ⏵ 从断点继续（已生成的报告不重算），⏹ 停止会丢弃断点但保留已生成的报告。

**⑦ 测试标签页（自动化评测）**
- 问题与参考答案来自问题库（自动同步）；🔄 **读取测试用例** 可在设置里改完“测试用例上限”后按新上限重派生问题。
- ▶ 批量测试（当前策略或全部策略），查看命中率 / 位次分析，结果可导出 Excel；测试过程中可 **暂停 / 继续 / 停止**（暂停在当前问题跑完后生效），停止后已测结果与统计保留。
- 🔥 **预热 / 向量缓存**（测试页工具栏按钮打开浮层）：浮层里是一张表，逐项列出 **批量生成摘要** 与 **摘要 / 切片 / 问题 / 实体向量缓存**（+ 社区报告），每行的勾选 / 状态 / 进度 / 耗时都在同一行（不会重复出现）；勾选后点 **开始预热** 执行。**已有摘要或向量一律跳过、不重复生成**（md 文件 frontmatter 里的「摘要」元信息、以及 .kb 里保存的摘要都算已有），已就绪的项用主题色显示（耗时单独计时、不计入检索时间）。
- 工具栏可直接选**评测用嵌入模型**（来自当前模型来源，无需进入设置）：选「跟随设置」即用设置里的嵌入模型；该选择不改动设置值，且随 .kb 保存。

**⑧ 设置标签页（调优）**
- 三个配置组：**知识库配置**（.kb 管理）、**策略配置**（自定义检索策略，见 5.3.1）、**处理配置**（切片策略、问题去重、测试用例上限、本体推理描述词与批量大小等，见 5.3）。模型来源统一跟随全局 AI 配置。

> 最快上手路径：**文件(选库/转换) → 切片 → 百科(开始抽取) → 问题(提取) → 问答**；之后回到顶部按需使用 本体 / 测试 / 设置。

### 5.2 新手建库 5 步流程

1. **准备文档**：把 `.md` 文档放入一个文件夹（PDF/Word 也支持，见下）。
2. **打开文件夹**：点右上角 📂 **打开文件夹** 选择该文件夹，系统自动扫描所有文件。
   - 若检测到 PDF/Word 缺少同名 `.md`，在**文件**视图会出现提示条，点 ✨ **转换** 按钮批量生成同名 Markdown。
3. **切片**：进入**切片**标签 → 选择切片策略（默认 / 智能 / 语义）→ 点 ✂ **剪刀按钮** 切分文档为片段。
4. **向量化**：点 🧲 **磁铁按钮**，为所有切片生成向量（调用当前 AI 来源的嵌入模型）。进度显示**已向量化/总切片**。
5. **保存知识库**：点右上角 💾 **保存知识库**，生成一个 `时间戳.kb` 文件。

> 建议再加一步（可选但推荐）：到**问题**标签点 ▶ **提取问题**，让模型为每个切片生成**可回答的问题**及参考答案，可显著提升检索效果；支持暂停 / 继续 / 停止，进度显示在底部状态栏。

**更新索引（增量更新）**：打开已保存的 `.kb` 后会自动检测文件变更（新增 / 修改 / 删除），弹窗询问是否处理；点**立即处理**走**增量更新**（重切变更文件 → 文件摘要 → 本体增量 → 社区 → 报告，未变化切片复用向量，幂等）。也可随时在**切片**标签点 🔄 **增量更新** 按钮手动执行。更新后重新**保存**生成新的 `.kb` 版本，可通过右上角版本下拉框切换。

> 📌 **文件标签页**：增量检测到变更时，顶部状态条显示**文件变更：新增 X / 修改 Y / 删除 Z**，文件名按状态着色（绿=新增 / 橙=修改 / 红=删除）并带徽标，一眼定位具体变更文件；PDF/Word 缺少同名 `.md` 时会提示，点 ✨ **转换** 一键规范化。

#### 5.2.1 问题库（问题标签）

**问题**标签管理问题库，是测试题与检索“问题增强”的数据源：

- **提取问题**：▶ 为未推理切片提取**问题 + 答案**对（答案与问题分开存储，下方蓝色行显示）；可暂停 / 继续 / 停止，进度在底部状态栏。
- **批量整理**：语义去重（按阈值自动分组，逐组由你决定保留/LLM 合并）、手动添加、Excel 导入 / 导出模板、生成需综合多切片的“复合问题”。
- **独立性评审** ⚖：由大模型逐条判定**问题 + 答案**能否被独立推导或由用户解出；不合适的问题在列表中**标红**（悬停看原因，点击该标记可忽略）。评审进度与**不合适 N**计数显示在**底部状态栏**（常驻项），**仅当前会话有效，不写入知识库**。工具栏 ✂ 图标可清除全部评审标记。
- **布局**：问题文本在左，来源 / 切片数 / 向量状态与操作按钮在右（悬停问题文本可查看所在文件）；列表**每 40 条下滑加载**，避免大数据量卡顿。

### 5.3 设置标签页（调优检索）

进入**设置**标签，左侧 3 个配置组：

- **知识库配置**：管理已有的 `.kb`（加载 / 删除），卡片化网格展示切片数 / 文件数 / 实体数 / 关系数 / 向量维度与状态标签（已向量化 / 已推理 / 含本体 / 社区 / 报告），悬停标签可查看含义。
- **策略配置**：自定义检索策略（见 5.3.1 自定义管线）。
- **处理配置**（切片与处理 + 本体推理，已合并）：切片策略（默认 / 智能 / 语义）、切片最大字符数、重叠字符数、语义切分阈值、问题去重 / LLM 合并开关、测试用例上限、**实体链接 LLM 兜底**（默认开；对话与嵌入模型在同一服务且显存有限时关掉它，本体增强策略评测会明显提速）、**保存向量数据到 KB 文件**（关闭=精简模式，KB 更小、首次检索按需补向量）、**保存测试结果到 KB 文件**（默认关；勾选后测试页的检索结果 / 位次分析 / 策略召回对比 / 智能路由检索过程随 .kb 落盘，重新加载即可查看与导出，无需重跑，代价是文件变大），以及**本体推理描述词**（实体类型、关系类型、卡片描述推理提示词）与本体批量大小。

> ⚡ 提速提示：LM Studio / Ollama 等单服务同一时刻只常驻一个模型，对话与嵌入模型交替调用会反复换载、非常慢。因此本软件默认「提取问题先推理、结束后统一补一次向量」「文件摘要先生成、最后统一嵌入」「实体 / 问题向量分批批量嵌入」，让同一模型一轮内只加载一次；只有把「实体链接 LLM 兜底」也关掉，本体增强策略的整轮评测才会完全不换载模型。

> 📌 模型来源统一跟随全局 AI 配置（设置 → 模型 → 来源），知识库内不再单独配置来源；嵌入模型可在知识库设置中调整（默认取该来源的默认嵌入模型）。

#### 5.3.1 自定义检索策略（处理管线）

问答与测试不再局限于固定模式，可在**策略配置**中**自定义检索策略**：左侧为策略列表（可搜索 / 新建 / 删除，内置 / 自定义标签），右侧编辑。

**策略类型**（4 种）：

| 类型 | 说明 |
|---|---|
| **管线组合** | 最灵活。自行编排**处理管线**+**检索管线**的原语步骤，每步可选原语、模式与参数 |
| **社区全局** | GraphRAG 风格 Map-Reduce：社区报告 → 并行分片总结 → 汇总全局答案 |
| **智能路由** | LLM 自主多轮检索，可开关 kb_search / file_search / entity_link / entity_slice / graph_hop / community_search 工具，**系统提示词可自定义**（留空=内置默认，按界面语言自动选择）；无相关数据的工具不会暴露给模型，最终位次由代码按相关度确定性排序 |
| **多路混合** | 同时启用稠密 / 稀疏 / 本体 / 图谱 / 社区多通道召回，统一排序（余弦重排 / RRF）取 TopK |

**两类管线**：

- **处理管线（构造管线，构建阶段）**：在**切片 / 向量化 / 增量更新**时执行，负责**构建**知识库的增强能力——产出语义向量、本体、社区与报告，供查询阶段消费。已处理的数据自动跳过（幂等）。可按需增删 / 排序下列处理原语：

  | 处理原语 | 作用 | 产出的增强 |
  |---|---|---|
| **问题语义增强** | 为问题库中缺失向量的问题补全问题向量（不再写回切片） | 问题库问题向量（检索 Q 增强通道；“问题增强”策略的依赖处理管线） |
| **文件语义增强** | 对每个文件聚合摘要并向量化，写入文件索引 | 文件摘要向量 fileIndex（文件级语义打分） |
| **本体推理** | 从切片抽取实体与关系，构建知识图谱 | 本体（实体 / 关系） |
| **社区检测** | 对实体图运行 Louvain 社区检测 | 社区划分（communityResult） |
| **报告生成** | 对每个社区调用 LLM 生成社区报告 | 社区报告（社区检索用） |

  > 📌 处理原语产出的增强能力（问题库问题向量 / 文件摘要向量 / 本体 / 社区 / 报告）供对应检索原语消费；若**检索管线**引用了依赖这些增强的检索原语但**处理管线**未配置对应原语，会提示**一键补齐**。

**内置策略参考**：新建策略时可选用以下内置为起点（也可新建为自定义管线）：

| 内置策略 | 检索思路 | 依赖处理管线 |
|---|---|---|
| **相似度** | 纯切片向量相似度（BM25 可选） | 无 |
| **问题增强** | 0.7×问题库问题向量相似度（取每条问题与查询的 max）+ 0.3×切片相似度 | 问题语义增强（自动补全问题向量） |
| **文件增强** | 纯切片基线分 + 文件级摘要分加权（文件为主） | 文件语义增强 |
| **本体增强** | 问题增强基准 + 实体命中乘性 boost | 问题语义增强 + 本体推理 + 文件语义增强 |
| **多跳** | 问题增强基准 + 沿关系图 2 跳扩展 boost | 问题语义增强 + 本体推理 + 文件语义增强 |

  > 需要混合检索（例如在文件增强后叠加问题/本体步骤）时，在“检索管线”里自行追加步骤即可。

**问题增强通道开关**：策略的检索管线若含“稠密检索”步骤，会显示“问题增强通道”开关——勾选 = 启用问题库问题向量增强（该稠密步骤的增强权重 >0），并自动在处理管线补上“问题语义增强”；取消 = 退回纯切片向量打分。
- **检索管线（查询阶段）**：每次提问按编排顺序执行的原语链（如 稠密召回 → BM25 → 实体链接 → 图谱多跳 → 社区筛选 → 加权融合），决定知识如何召回与打分。每个步骤可选模式：设置基础分 / 乘性提升 / 加权融合 / 取最大。

**检索参数**：每个策略独立配置召回数量 TopK、检索模式（按数量 / 按匹配率 / 按字符）、匹配率阈值、字符限制、BM25 开关与权重；支持启用 / 停用 / 恢复默认。配置后，**问答**下拉与**测试**即用当前策略执行。

### 5.4 问答标签页与测试标签页（进阶：检索模式与自动化评测）

**问答**标签默认提供多套内置检索策略（默认在**问答**下拉启用，可在**策略配置**中启用 / 停用 / 自定义，下拉显示全部已启用策略）：

| 策略 | 说明 |
|---|---|
| **相似度** | 标准向量检索：切片相似度 |
| **文件增强** | 以文件级摘要分为主的检索（文件语义） |
| **问题增强** | 以问题库问题向量为增强通道（0.7 问题 + 0.3 切片） |
| **本体增强** | 先匹配本体实体，对关联切片做乘性 boost 再检索 |
| **多跳** | 沿实体关系图 BFS 扩展 2 跳，增强相关切片 |
| **社区** | GraphRAG 风格：社区报告 map → reduce 汇总 |
| **Agentic** | LLM 自主多轮检索（智能路由）：模型自行选择检索工具与检索词，直到资料充分；工具可开关、系统提示词可自定义，测试页可用「过程」按钮回看每次工具调用，主页检索时按智能体模式的工具卡片展示同一轨迹 |
| **多路混合 / 稠密+社区** | 多通道召回统一排序 / 稠密与社区报告融合 |

> 💡 若知识库尚未切片 / 向量化，直接在问答框提问会自动完成准备（切片 + 向量化）再检索，无需手动操作。

右侧**佐证面板**显示本次回答引用的证据（文件名、来源方法、相似度分数、内容摘要）。

**测试**标签可进行**自动化评测**：问题与参考答案来自**问题**标签的问题库（自动同步）；工具栏 🔄 **读取测试用例** 按钮可在**设置 → 处理配置**中修改“测试用例上限”后，按新上限从问题库**重新派生问题**。运行批量测试后可查看命中率、相似度与**位次分析**，对比不同算法的检索效果，结果可导出 Excel。

**策略召回对比**（批量测试面板）除召回率 / Hit@1 / MRR / 完整率 / 平均位次外，还提供：

- **成本列**：模型调用 / 题（Agentic 的工具轮与最终作答、社区 Map-Reduce 都计入）与工具调用 / 题（悬停看工具分布），便于按“召回-成本”权衡；
- **重复次数**：工具栏数字框设定（仅「批量测试所有策略」生效），同批问题重复跑 N 轮，各指标显示**均值 ± 标准差**，用于判断差异是否稳定；
- **配对显著性检验**：选定基线后，对同一批问题做配对比较——命中差异用 **McNemar 精确检验**（b/c 为基线独有 / 对比独有的命中数），位次差异用 **Wilcoxon 符号秩检验**（未命中记 K+1），给出 p 值与“显著更优 / 更差 / 无显著差异”的结论，避免把噪声当提升；以上均可导出 Excel（含「配对显著性」工作表）。
- **命中判定口径**：除「切片命中」（按关联切片身份）与「答案命中」（按参考答案文本，含精准 / 模糊子策略）外，还可选 **「大模型判定」**（**仅智能路由类策略可用**）：由对话模型对比「检索到的片段」与问题 / 参考答案，判定**是否命中与最前命中位次**——同义改写、答案分散在多个片段中也能判为命中（切片身份比对会漏判这类情况）。判定调用在检索计时之外执行（不计入平均检索时间），但计入「模型调用 / 题」成本列；判定失败（模型未返回 JSON）时该题记为「无基准」而不误判为未命中。批量测试所有策略时，非智能路由策略会自动回退到切片 / 答案口径。
- **检索过程**：智能路由（Agentic）类策略的结果行有「过程」按钮，点开可回看该问题当次的工具调用轨迹（轮次 / 工具 / 参数 / 返回内容），用于确认“到底是模型调了工具，还是只吃了单轮基线”。

> 💡 评测前若切片缺少向量（例如用的是**精简模式**保存的 .kb），会自动补齐向量再开测——否则相似度分全为 0，总分也会显示 0%。

> 💡 若在「设置 → 处理配置」勾选了**保存测试结果到 KB 文件**，以上结果（检索结果 / 位次分析 / 对比统计 / 检索过程）会随 .kb 一起保存，重新加载知识库即可直接查看与导出，无需重跑；结果按切片 id 回源，重新切片或换库后旧结果的正文与命中标记可能失配。

### 5.5 百科标签页与本体标签页（进阶：实体与图谱）

两者查看**同一份本体数据**的不同视角：**百科**把实体当“卡片 / 条目”浏览管理，**本体**以图谱方式查看概念、关系与社区。标签顺序为 **… 问题 / 百科 / 本体 / …**（百科在本体之前）。

- **百科（构建与卡片）**：实体概念抽取（即“本体构建”）的入口在百科页：
  - ▶ **开始抽取实体**：从切片抽取实体、关系并生成描述，产出百科卡片与本体图谱；运行中可 暂停 / 停止，**进度只显示在底部状态栏**（页面内不显示进度）。
  - ↻ **继续**：加载带“未完成断点”的知识库时，百科只显示**继续**（从断点恢复），不会自动运行；也可用底部状态栏的 ▶ 继续处理知识库。
  - 🗑 **清空本体/百科**：删除全部实体（即百科卡片）及其实体间关系与派生社区，**切片不受影响**；点击需确认，清空会同时终止正在运行的后台构建，并回到**开始**态。
  - ➕ 手动添加实体、批量生成描述、卡片搜索。
- **本体（图谱）**：知识图谱可视化（平移 / 缩放、点击节点看详情 / 关联切片）：
  - ⛓ **手动连线**：点连线按钮进入连线模式，依次点两个**概念节点**，由大模型自动判定关系类型（仅概念 ↔ 概念；引导与结果提示显示在底部状态栏）。点空白可取消当前选择。
  - 实体 / 切片 / 文件 / 问题节点开关、社区检测、生成报告与社区筛选仍在本体页；清空与构建控制已移到百科页。
  - 若某概念是模型归纳出的名字而原文未出现，会被**保留为孤立概念**（不再静默丢弃），可在百科“手动添加实体”补关联，或之后有同名字面命中时自动补挂。

### 5.6 在主页中使用知识库

回到**主页**聊天 → 点击输入框的 📖 **知识库模式**按钮 → 选择刚才保存的 `.kb` 文件 → 输入框变为**输入问题，将检索知识库后回答**，可在输入框上方选择**检索策略**（相似度 / 本体 / 多跳 / 社区 / Agentic）并调整片段数量，提问即可。回答会标注**参考了 N 个知识片段**及来源。

## 六、学习（掌握式记忆与复习）

学习模块把**知识处理**保存出的 **.kb 知识库** 变成可以“学会”的内容：围绕文件与本体实体追踪掌握度，并用**间隔复习**安排到期提醒，配合闪卡练习、错题本与考试，形成 **练习 → 复习 → 考试** 闭环。

- **前置**：先在**知识处理**切片 / 向量化并保存生成 `.kb`。
- **进入**：点击顶部导航的 🎓 学习，右上角下拉选择知识库。下拉会扫描**全部工作区及其子目录**（工作区在 设置 → 通用 → 基础 → 路径设置 里管理），`.kb` 不在当前工作区也能选到；同名库会补标所在目录，下拉旁的 ⟳ 可手动重扫。
- **数据**：学习记录（作答 + 已生成的 AI 解析）独立保存为知识库旁的 `<库名>.learning`，**绝不写入 `.kb`**；知识库更新后旧记录标记“过期”保留。

### 6.1 六大视图

| 视图 | 说明 |
|---|---|
| 总览 | 行动中心：下一步建议；整体掌握 / 正确率 / 累计练习显示在底部状态栏；连续学习打卡与近 7/30 天趋势 |
| 学习地图 | 三种轴：**按文件** / **按实体**（卡片底部横向进度条；图标操作：练习、复习、声明已掌握(跳测)、切换知识类型、清除过期 / 重学）/ **本体图谱**（实体关系图，节点颜色即掌握状态；范围下拉可选 全部实体 / 仅已练习 / 全部实体+问题 / 仅已练习+问题 / **切片+问题** / **文件+问题**：后两种把切片或文件与问题一起画出来，问题连到它依据的切片 / 来源文件，点切片可只练这一片、点文件可练整个文件；点实体节点看详情或开始练习。图例栏可设**节点间距**（紧凑 / 标准 / 宽松 / 很宽，默认宽松——节点挤在一起时调大）、**显示数量**（200 / 500 / 1000 / 2000 / 5000 / 10000 / 20000，默认 2000）与**节点标题**（跟随数量 / 总是显示 / 不显示，节点越多字号自动越小），超出时图例会标出**已画 / 共多少**） |
| 复习 | 到期队列（近期答错 / 连续答错优先），一键开始到期复习；练习卡底部三个标签：**答案 / 解析 / 参考切片**（出处切片按 Markdown 渲染），右上**答案区**可整块隐藏用于自测 |
| 错题本 | 左列表 + 右详情：参考答案(来源切片)、错因标注(记忆 / 概念 / 步骤 / 粗心)、AI 讲解与图解讲解、重练此题 |
| 答疑 | 就当前知识库直接提问：答案只依据检索到的切片生成，逐条标注引用编号 [n]，可展开切片原文核对 |
| 考试 | 随机 / 勾选切片 / 手动 / 真题仿写四种出题方式(单选 / 多选 / 判断 / 问答)；客观题本地判分、问答题 AI 评分；可把每题计入对应文件学习对象 |

### 6.2 掌握度与门控

每个文件按作答正确率计算掌握度（0–100%），达到 **90%** 门控即“已掌握”；答错会回退，未达标的保持“学习中”，可在地图随时练习。

### 6.3 分型间隔复习

对象按**知识类型**（地图卡片可手动切换；新建时按切片正文启发式推断）使用不同复习节奏：

| 类型 | 间隔（天） | 说明 |
|---|---|---|
| 记忆 memory | 1 / 3 / 7 / 14 / 30 / 60 | 事实记忆，复习最密 |
| 步骤 procedure | 3 / 7 / 14 / 30 | 步骤 / 技能 |
| 概念 concept | 3 / 7 / 14 / 30 / 60 | 概念理解 |
| 设计 design | 14 / 28 / 60 | 开放设计判断 |

规则：答对拉长间隔（**连续答对 2 次跳两档**），答错缩短（连续错 2 次重置）；“到期”对象进入**复习**队列（近期 / 连续答错优先）。**练习不受到期限制**，任何时候都能手动刷；答错当天也可在错题本“重练此题”。

### 6.4 地图卡片操作

卡片底部为横向掌握进度条（颜色=状态：绿=已掌握 / 橙=学习中 / 空灰=未开始）。右上角图标：练习 /（到期）复习；未掌握卡片可 **✓ 声明已掌握（跳测）** 跳过已会内容；点击类型图标可在 记忆 / 步骤 / 概念 / 设计 间切换。知识库更新后旧记录标记“过期”，可用 撤销标记 / 清空重学 处理。

### 6.5 错题与考试联动

- 错题本每条错题可标注**错因**（记忆混淆 / 概念不清 / 步骤错误 / 粗心），便于复盘。
- 考试工具栏左侧 🔗 开关：开启后交卷会把每题作答计入对应文件学习对象，同步驱动掌握度与复习。

### 6.6 解析与真题仿写

- **练习卡的三个标签**：卡片底部依次是 **答案**（参考答案或来源切片正文）、**解析**（AI 把当前知识点拆成**一句话核心 / 前置概念 / 分步推理 / 易混点**并画一张知识结构图 mermaid 流程图；首次切到该标签时才生成、**逐字流式输出并实时渲染 Markdown**、换题重新生成）、**参考切片 N**（该题依据的出处切片，按 Markdown 渲染，公式 / 表格 / 图都能正常显示）。右上**答案区**按钮可整块隐藏面板，先自测再看答案。
- **Markdown 排版**：解析 / 参考切片 / 错题讲解里的段落、列表、多级标题、代码、表格、图与主页一致，不再出现上下留白与缩进不一致。
- **输出语言**：解析正文与图内节点标签都**优先用中文**（专有名词 / 缩写可保留英文，如 LP、KKT），只有当知识库正文本身是英文、或界面切到英文时才用英文。
- **解析会保存**：解析生成完会随学习记录存进 `<库名>.learning`（按**切片 + 题干**缓存，最多 300 条自动淘汰最旧），再打开同一题直接显示、不再重复花 token；页脚会显示保存时间，点**重新生成**可重新调用模型。
- **错题的 AI 讲解**：错题详情的**图解**按钮同样生成上面的图文讲解。
- **答疑（智能体模式）**：在**答疑**页签输入问题（`Enter` 发送、`Shift+Enter` 换行）；上方的示例卡点击只**填入输入框**，可改完再发。答疑走的是与主页相同的**智能体循环**（自动调用 `kb_search` 按需多轮检索，必要时用 `search_files` 按文本查找或 `read_file` 读原文），因此总览性问题也能自己分侧面查；回答逐字流式输出，卡片上带**执行步骤**（每步调用了哪个工具、命中多少条，完成后折叠为一行可点开），底部**引用切片**列出智能体实际用到的切片可供核对。
- **答疑的回退**：若当前环境没有智能体运行时（如纯网页端），或未配置对话模型，会给出提示；向量检索不可用时智能体会改用关键词查找并在回答里说明。
- **答疑的两种上下文**：问“具体某个点”（如“单纯形法的步骤”）走向量检索 top-5 片段；问“总览性”问题（如“整体讲了哪些核心概念”）会自动切到**概览模式**，改用文件级摘要 + 每文件代表切片 + 本体实体清单，避免只凭零散几片答不全（卡片上会标**概览模式**）。当前来源没有可用嵌入模型时，检索自动降级为本地关键词匹配并标注**关键词兜底**，不影响提问。
- **真题仿写**：考试页**真题仿写**模式 → ① 点右上角文件夹导入（支持 `.md/.txt/.docx/.pdf`）或直接粘贴真题/样卷 → ② 点**分析真题风格**得到题型配比、题干措辞、选项与答案风格（风格档案按知识库保存在本机，可随时复用或清空）→ ③ 工具栏设置题数并点**生成**，即按该风格仿写出新题。
- 三种能力都要求先在设置里配好可用的 AI 模型；未配置时会在对应位置给出提示。

## 七、通用文件（Markdown · 文档 · 图表 · 白板）

**通用文件**是你日常真正读写的东西：Markdown 笔记、Word / PDF 文档、图片音视频、纯文本、Excel、本地网页，以及两张画布——**Excalidraw 白板**与 **draw.io 图表**。它们都在**知识管理**里创建与打开，双击即用最合适的视图渲染；这一章讲**用什么视图看 / 怎么编辑 / 怎么导出**。

| **编辑** | Monaco 代码编辑器，支持 AI 辅助、拖入图片/文件生成引用链接；代码与数据文件（`.py` / `.json` / `.flow.yml` 等）也在这里以文本方式打开 |

| **日历** | 月视图 / 周视图 / **年视图** / **甘特图** 四合一（底部状态栏切换），可拖拽改期、日期格内新建；条目上**右键**可 打开 / 重命名 / 设置时间 / 颜色 / 归档 / 复制文件路径 / 在文件夹中显示 / 删除（与看板卡片同一套菜单，点日期弹出的列表里也能用） |
| **地图** | 按文件 YAML 里的 `纬度` / `经度` 在地图上打点（可一键只显示有经纬度的文件），点标记或右侧列表打开文件；地图无搜索需求，工具栏只显示路径 |
| **表格** | 一行 = 一个文件、一列 = 一个 YAML 属性的表格，单元格直接改 frontmatter；默认只列 **Markdown**（状态栏**范围**可切**全部**，非 Markdown 整行只读），**列按当前深度范围的属性生成**，列头点击即排序 / 列菜单可筛选与指定列类型 / 列可拖拽换序与调宽 / 可隐藏列，见下方说明 |

> **特殊文件不走文件视图**：`.kb` 知识库双击后跳到**知识处理**加载该库，可检索、问答与重新切分（见 五、知识处理）；`.task` 任务文件双击后在独立窗口里打开专属**脚手架**视图（导入表格、运行、看日志与结果都在里面，见 8.3）。

> **各视图共用的顶部工具栏（路径 + 搜索）**：**文件 / 看板 / 表格 / 图谱 / 地图 / 日历** 六个视图共用**同一条**顶部工具栏：最左侧是**显示 / 隐藏左侧文件树面板**的开关（收起 / 展开带滑出动画），接着是**视图选择**下拉（在 6 个全局视图之间切换），然后是 **后退 / 前进 / 向上 / 刷新**，中间是**可点击跳转的路径面包屑**（悬停可看完整路径），右边是**搜索框**（面板窄时搜索框自动收窄，把空间让给路径；工具栏过窄时还会收起导航按钮与路径面包屑、搜索框改占满剩余宽度，快捷键 `Alt+←` / `Alt+→` / `Backspace` 仍可用）。搜索框也是共用的、语法各视图一致：直接输入关键词即按**文件名 / 路径 / 属性值**过滤，也支持 `状态:待办`（属性包含某值）与 `优先级>2`（数值比较，还可写 `>=` `<` `<=` `=`）；含空格的关键词用双引号包起来。各视图按同一结果过滤自己的内容（图谱按节点、表格按行、看板按卡片、日历按条目），地图没有搜索需求所以只显示路径。切换视图、**双击文件树里的文件夹**或点面包屑都会同步路径，后退 / 前进的历史在各视图之间共用；底部状态栏只放各视图自己的设置与计数，不再放搜索框。

> **日历视图（含年视图 / 甘特）**：底部状态栏左侧**视图**下拉可切换 **月视图 / 周视图 / 年视图 / 甘特图**（选择会记住）。月视图为整月表格，周视图为单周 7 天（两种视图的**今天**整格用强调色描边高亮）；两种日历下，**表内条目可直接拖到另一天**＝改期（写入文件的 YAML 时间字段），格内悬浮出现 **+** 可直接在该日期新建 Markdown 条目（建在**当前文件夹**，并自动设好日期）。**条目上点右键**是与看板卡片**完全一致**的操作菜单：打开 / **重命名** / **设置时间**（弹出与看板相同的时间面板，直接改开始 / 结束时间，留空即删除该属性）/ **颜色**（预设色板随主题切换，也可用取色器自定义或清除）/ **归档**（写入文件的 `归档` 属性，与看板同一套）/ 复制文件路径 / 在文件夹中显示 / 删除（删除会二次确认）；点日期弹出的**当天条目列表**里同样可以右键。**已归档条目默认不显示**，点状态栏右侧的**归档图标**即可临时查看（在日历里归档 / 取消归档都走条目右键菜单）。**年视图** 一屏列出 12 个小月：列数随面板宽高自动在 2~6 列间变化并始终铺满可视区（窗口缩放 / 与其它视图并排拖动分隔条都会实时重排），有事件的日期显示一个圆点（悬停看条目名称），点日期弹当天列表、点小月标题进入该月月视图；年视图内不做新建/改期。甘特图模式沿用原有甘特能力（缩放 / 层级 / 起止时间字段 / 跳转到今天），**只排期 Markdown 文件**（文件夹与图片 / 数据等格式不参与），任务名同样不带后缀；任务条**带边框并用条目 `颜色` 上色**（无颜色时用主题强调色），浅色 / 深色主题下都清晰可见。仅 **Markdown 文件**（或含 `.README.md` 的文件夹）可拖拽改期。

> **日历的区间 / 颜色 / 状态 / 搜索**：条目同时有**开始时间**与**结束时间**（字段可在状态栏选择，与甘特视图共用）时，会在日历上**横跨每一天**显示——首尾切直角、中间淡底，拖拽时**整段平移并保持时长**（单日条目只写起始字段）。条目的 **`颜色` 属性**会作为条目条底色（并自动选黑/白文字色），**`状态` 属性**会显示内置图标（灵感 / 规划 / 待办 / 进行中 / 已完成 / 未完成 / 已取消 / 已搁置，其它取值不显示图标）；颜色可在**表格视图**的 `颜色` 列点开取色器设置，也可在日历条目上**右键 → 颜色**直接点选预设色 / 自定义 / 清除。**顶部工具栏的搜索框**按**标题 / 状态 / 任意属性值**筛选当前日历里的条目，计数变成**命中 / 总数**，Esc 或 × 清除。日历里的条目名**不显示 `.md` 后缀**；**日历（月 / 周 / 年）与甘特都只显示 Markdown 文件**（文件夹、图片 / 数据 / 代码等格式不参与），任务名同样不带后缀。

> **文件视图的属性筛选**：底部状态栏**筛选**可先选一个 **YAML 属性**（如 `状态`），再选该属性的取值（含**（未设置）**）即可筛出当前目录下的匹配文件；与顶部工具栏的搜索可叠加使用，× 可一键清除。

> **表格视图（按列整理属性）**：一行 = 一个文件、一列 = 一个 YAML 属性，改单元格就是改文件的 frontmatter。**数据范围**：默认只列 **Markdown**（状态栏**范围**可切**全部**，此时文件夹与图片 / 数据等格式整行只读，避免误改二进制文件），**深度**可选读取几层子目录。**列能力**：**列按当前深度范围内的属性生成**——改深度或换目录时列会跟着变（不会残留只有更深层 / 别的目录才有的属性，那些列整列都是空的）；点列头按该列排序（升 → 降 → 取消，空值恒排最后），列头的 ▾ 菜单可**按取值筛选**（含**（未设置）**，多选取值即只显示这些值）、**指定列类型**（文本 / 数字 / 日期 / 日期时间 / 复选框 / 颜色 / 单选 / 标签）、重命名属性（批量改文件里的属性名）或隐藏此列；拖动列头可**换序**、拖列头右边界可**调宽**，状态栏右侧的列按钮可批量显隐（并在面板底部列出**当前深度内没有、但之前配置过的属性**，点一下即加回；面板右上角 **+** 可手动加一个新属性列，显式添加的空列在列表里有垃圾桶图标可移除），列序 / 列宽 / 类型 / 排序 / 筛选都会记住。**单元格编辑**：单击或 Enter 进入编辑，Esc 取消，方向键 / Tab 移动，Delete 清空该属性；类型不明时按该列已有取值推断（`状态` 列直接使用**状态分类**配置的取值与图标，颜色列给出取色器，标签列按逗号分隔）。**批量与粘贴**：勾选行首复选框后可**批量设置属性 / 删除属性 / 删除文件**（只作用于可编辑的 Markdown），选中单元格后可直接**粘贴 Excel 的多行多列**（会先确认要写入多少单元格 / 文件）。**行操作**：点文件夹行的文件夹图标即**进入该文件夹**（顶部面包屑随之切换，其它视图也一起切过去），文件行则按**设置 → 文件操作**打开；行上**点右键**可打开 / 进入文件夹 / 在系统文件管理器中打开（文件夹）/ 新窗口打开 / 在文件夹中显示 / 复制路径 / 新建同级 Markdown / 重命名 / 删除。

> **看板视图**：把任务做成知识库里的普通 Markdown 文件——**一张卡片 = 一个 `.md`**（frontmatter 写 `状态` / `颜色` / `开始时间` / `结束时间` / `归档`），因此同一条条目能同时出现在看板（分组 / 拖拽改值）、日历（拖拽改期）、甘特（排期）、表格（改颜色等属性）里，也能被全文搜索与知识库检索到。用法：点**左下角状态栏的 ➕**（紧跟**当前文件夹**名称右侧）打开**新建卡片面板**——填**名称**（必填，自动补 `.md`）、**状态**（即当前分组字段的取值，选**不设置**则留空）、**开始时间**与**结束时间**（都可留空，开始时间**默认今天**，因此新建后立刻能在日历 / 甘特上看到），回车或点**创建**即在**当前文件夹**里建好；想换状态直接把卡片拖到别的列即可；**每张卡片右侧都有日历图标**，没有时间的卡片点它即可补上**开始 / 结束时间**（已有时间时图标常亮，点开可改）；**看板**形式下列是**分组**字段的各取值，把卡片从一个列**拖到另一列**即改该属性的值（拖到**未设置**列＝清除该属性）；**列表**形式下每行左侧的下拉框可直接改当前分组字段的取值；卡片 / 列表行上**点右键**打开操作菜单（打开 / 重命名 / 设置时间 / 移入某个取值 / 归档 / 复制文件路径 / 在文件夹中显示 / 删除，删除会二次确认；重命名时填卡片名即可，没写扩展名会自动补回 `.md`，**设置时间**与点卡片右侧日历图标是同一个面板），卡片标题下方直接显示**起止时间**（如 `10-08 → 10-10`，只填了一天就只显示一天；结束字段除了 `结束时间` 也认 `截止时间` 等常见写法），这段文字**只是展示**，**点卡片右侧的日历图标**才会弹出小面板直接改开始 / 结束时间（改完即写回 frontmatter，日期改空则删除对应属性）；悬停日期或图标可看到时间取自哪个字段。已归档的卡片默认不显示，点状态栏右侧的**归档图标**即可查看或隐藏。**取值筛选在状态栏的筛选图标里**：点开后在面板里**多选**取值（每个取值带当前范围内的卡片数，点**全部**或橡皮擦清除，按钮上带已选数量角标）；取值很多时面板会自动换行并纵向滚动，不会挤占卡片区；切换分组字段时会**自动清空筛选**与新建默认值。状态栏从左到右是：**当前文件夹 → ➕ 新建卡片 → 分组字段 → 看板 / 列表 → 读取深度 → 隐藏空列 → 筛选 → 归档显示 → 计数 → 状态分类 → 刷新**，各下拉与按钮只留图标（含义悬停可见），窄面板时只留 分组 / 视图 两个下拉 + 新建 + 筛选 + 计数。

> **状态分类（顺序 / 图标）**：点看板状态栏最右侧的**标签图标**打开**状态分类**面板，可**上移 / 下移**调整 `状态` 分类的列序、用下拉**更换图标**、**新增**自定义分类（如**紧急**）、**移除**不需要的分类，或一键**恢复默认**（默认：灵感 / 规划 / 待办 / 进行中 / 已完成 / 未完成 / 已取消 / 已搁置）。配置保存在本机，并**与日历的状态图标共用**——改完看板与日历同时生效。移除某个分类**不会改动文件里已写的取值**：文件里仍用到的取值会作为额外列排在配置列序之后（图标退回内置表，未知取值不显示图标）。**只出现在文件里、不在分类表里的取值会列在面板底部**，可一键**加入**到表内——加入后它们的列序才由这里控制（未加入时按内置默认顺序排在已知取值之后；与表内取值只差零宽空格 / 成对引号这类不可见字符时，按表内那一项处理）。⚠ 看板只收纳 **Markdown 文件**，文件夹与图片 / 表格等格式不参与（需要文件夹 / 任意格式的浏览请用**文件**视图，属性批量改值请用**表格**视图）。

> **Excalidraw 白板**：`.excalidraw` 文件支持在浏览器中直接拖拽绘制流程图、草图等（工具栏图形/文本/画笔），可**嵌入网页、图片、视频**，支持 `Ctrl+S` 保存到当前文件，也可以在文件上右键新建 `.excalidraw` 白板。

> **draw.io 图表**：`.drawio` / `.dio` 文件内嵌 draw.io 官方编辑器绘制（完全离线），支持编辑、导出、**复制为图片（直接粘贴到 Word / PPT）** 与 **AI 智能操作（生成 / 调整 / 删除图形）**，详见 7.4。

> **工作流编辑器**：`.flow.yml` / `.flow.yaml` 文件在**浏览 / 可视编辑**视图打开工作流编辑器（节点库 / 属性面板 / 运行面板），**源码编辑**视图显示 YAML 文本，详见 8.2。

> **右侧视图切换下拉**决定当前文件用哪种视图打开（浏览 / 源码编辑 / 可视编辑 / 思维导图 / 演示）。不同文件类型可用的视图不同：代码类只有源码编辑，图片 / 音视频 / PDF 只有浏览，`.flow.yml` / `.flow.yaml` / `.flow` / `.workflow` 只有流程画布，`.data` 只有数据画布，`CSV` / `TSV` 只有浏览 + 源码编辑，Excel（`.xlsx` / `.xls`）只有浏览（表格由转换结果渲染，不提供源码编辑）；可用视图只有一种时**不显示这个下拉**。

> 右侧视图支持水平/垂直排列，拖动分隔条调整大小。这些视图由 Markdown 文件头部的 **YAML frontmatter 元数据**（如 `状态`、`开始时间`、`结束时间`、`颜色`、`经度`、`纬度` 等）驱动——浏览视图底部状态栏的**标签图标只做只读展示**（查看标签与属性，不再在浏览视图里编辑），需要修改时请切到**源码编辑**视图改文件头部 YAML，或用看板 / 表格 / 日历 / 甘特视图里对应的编辑操作。除**文件**视图外（它用顶部面包屑显示路径），日历 / 看板 / 表格 / 图谱 / 地图的**底部状态栏最左侧会显示当前文件夹名称**（悬停看完整路径），它们也都**跟随文件视图的当前目录**取数据（越出工作区时自动回退到工作区根）。看板 / 表格 / 图谱 / 地图 / 日历的**状态栏深度**可选择读取到第几层子目录，看板还能**一键隐藏空列**。表格里的**文件夹**不会打开浏览视图，而是用系统文件管理器打开该文件夹；**看板只显示 Markdown 文件**（文件夹与图片等格式不参与，需浏览它们请用**文件**视图）。

### 7.2 Markdown 与文档编辑（浏览 / 源码编辑 / 可视编辑 / 导图 / 演示）

同一个 `.md` 文件可以换着方式打开：右键 → 打开 → 选对应视图即可。

| 视图 | 适合做什么 |
|---|---|
| **浏览** | 只读预览：公式、代码高亮、表格、图片、Mermaid 图、内嵌 draw.io 图表都能渲染；底部状态栏还有两个进阶能力——✨ **智能操作**（与当前文档智能对话）与 ⬇ **导出 Markdown / Word / PDF** |
| **源码编辑** | Monaco 编辑器直接改 Markdown 原文，支持 AI 辅助、拖入图片 / 文件自动生成引用链接 |
| **可视编辑（块编辑）** | 块式富文本：输入 `/` 唤出块类型菜单，块手柄菜单的**转换为**可在标题 / 列表 / 表格 / 代码间转换 |
| **导图** | 按标题层级生成思维导图（支持 LaTeX 公式节点，节点宽度与展开层级可在状态栏调） |
| **演示** | Markdown 转 PPT：按 `---` 或**智能切分**分页，支持目录 / 总览 / 全屏、主题切换与多种图片排版 |

**其它文档类型**：Word（`.docx`）自动转 Markdown 渲染并可导出 Markdown；PDF 支持逐页浏览 / 缩放 / **OCR** / **原地翻译**（选中右键**翻译**，或点右下角 🌐 图标整份叠加译文）；Excel（`.xlsx`）转 Markdown 表格；图片 / 视频 / 纯文本各有对应预览；本地网页（`.html` / `.htm`）默认交给**内置浏览器**渲染，AI 还能继续对它操作。

> **导出**：浏览视图与 Markdown 文档的**导出文档**菜单里有**导出 Markdown / 导出 Word / 导出 PDF**，其中前两者会弹出另存为对话框（Word 另有导出样式：公文 / 中文论文 / 英文论文 / 自定义 `.docx`，公式优先转为 Word 原生可编辑公式）。

### 7.3 Excalidraw 白板（`.excalidraw`）

手绘风格的无限画布，适合画草图、流程图、示意图：矩形 / 椭圆 / 箭头 / 文字 / 自由笔。

- 在目录树或**文件**视图右键 → 新建 → **Excalidraw 白板** 即可创建；双击进入**白板视图**。
- 编辑**自动写回文件**（`Ctrl+S` 可立即保存）；支持图片等嵌入内容。
- 右下角的**协作按钮**可把白板共享给局域网内的成员（见 [4.6 局域网协同编辑](#46-局域网协同编辑重点)）。

### 7.4 draw.io 图表（`.drawio` / `.dio`）

知识管理内置 **draw.io 图表编辑器**：draw.io 官方 webapp 随软件打包，**完全离线可用**，无需另外安装 draw.io 或联网。

- **支持的文件**：`.drawio` / `.dio`；内容含 `<mxfile>` / `<mxGraphModel>` 的 `.xml` 也会被识别为图表（避免把普通 xml 误判）。
- **打开方式**：在**浏览 / 编辑 / 块编辑 / 导图 / 演示**任一视图中打开都会直接渲染为绘图画布；远程共享的图表与协同中的只读成员为**只读预览**（显示锁形徽标）。
- **在 Markdown 里内嵌图表**：写 `![说明](图.drawio)`，**浏览 / 可视编辑 / 思维导图 / 演示**四个视图都会把图表直接画在正文里（不用先截图），点击图表即打开编辑器并**直接定位到所点的那一页**；**多页图表逐页依次内嵌**（超过 10 页只渲染前 10 页并提示；导图节点里只放第一页），只看某一页写 `![说明](图.drawio#page=2)`（1 起的序号，也可用页名 `#page=页名`）；导出 Word / PDF 时图表会一并输出（多页各出一张图）。远程只读模式下不内嵌，改为点击打开编辑器。

#### 7.4.1 创建与打开

1. 点目录树顶部的 **➕ 创建文件**，在弹窗中把类型切到 **draw.io**（会自动写入一个空白图表框架，避免留下 0 字节文件）；或在文件树右键**新建 → draw.io**。
2. **双击** `.drawio` 文件即进入图表视图；画布与 draw.io 桌面版一致（左侧图形库、右侧格式面板、底部页签栏）。

#### 7.4.2 编辑与保存

- 编辑**不会自动写盘**：右下角 **💾 保存按钮会出现橙色小点**，表示有未保存的改动；点 💾 或按 `Ctrl+S` 才写回原文件。
- 保存成功会提示**已保存到 xxx.drawio**，并通知其它窗口 / 预览刷新（不会出现磁盘已写但界面仍是旧内容的情况）。安全兵底：切标签 / 换主题 / 关窗口时会静默写盘，不会丢内容。
- 文件格式：写回的是完整 `<mxfile>`（`<diagram>` 内为未压缩 `<mxGraphModel>`），首次编辑后压缩过的旧文件会转为未压缩格式。

#### 7.4.3 导出 / 另存为 / 打印

- 菜单**文件 → 导出为**支持 PNG / JPEG / SVG / XML 等格式。
- **下载**与**另存为到设备**已改为**系统原生保存对话框**，可自选位置（默认当前图表所在目录），不会静默丢进系统下载文件夹。
- **导出为 → PDF**与**文件 → 打印**走应用的**本地打印通道**（隐藏窗口渲染当前页 → printToPDF / 系统打印对话框），**离线可用**；多页图表只导出**当前页**。
- **文件 → 保存为**可另存为一个新的 `.drawio` 文件。

#### 7.4.4 复制为图片（直接粘贴到 Word / PPT）

- 点画布**右下角的 📋 复制为图片**（快捷键 `Ctrl+Alt+X`），或从菜单里选一档清晰度：

| 档位 | 适用场景 |
|---|---|
| **高清 4×**（默认） | 插图到 Word / PPT 后仍然锐利，打印不虚 |
| **标准 2×** | 文件体积与清晰度均衡 |
| **原始 1×** | 图表很大、只想快速粘贴或体积敏感时 |

- 图片会直接进**系统剪贴板**，切到 Word / PPT / 聊天窗口 `Ctrl+V` 即可，**不必先保存文件**（未保存的改动也会一起带过去）。
- 输出为**白底**、按图表原始大小排版（高清不会把图撑满整页，粘贴后尺寸不会变成 4 倍）；超大的图表会自动降档，避免卡顿。
- 只输出**当前页**；图里的图片、换行标签等均按画布所见还原。

#### 7.4.5 智能操作（AI 生成 / 调整 / 删除图形）

点画布**右下角的 ✨ 智能操作**按钮，右侧弹出 AI 面板：

1. 用自然语言描述需求，例如**加一个三步审批流程：提交 → 审核 → 归档**、**把左边的节点改成红色并右移**、**删除 A 到 B 那条连线**。
2. AI 先读取当前图表内容（已有图形 / 连线 / 页数，并自动避开已有内容找空白区），生成**增量片段**。
3. 结果**直接在画布上预览**（面板列出**新增 / 调整 / 删除**明细与图形文字列表，此时**尚未写入文件**）。
4. 点**确认应用**才写入文件（提示新增 x、调整 y、删除 z）；点**取消**则原样回退到改动前。

| 模式（输入框左侧下拉） | 说明 |
|---|---|
| **自动可调**（默认） | 可新增图形/连线，也可调整已有图形的位置 / 尺寸 / 文字 / 颜色 / 层级 / 连线，或按 id 删除 |
| **仅新增** | 只添加新图形与连线，绝不改动已有内容；新图形会自动避让到空白区域 |

> 💡 生成中可点**停止**中断；若模型返回的内容不是合法 XML，会提示失败并提供**重试**按钮。协同会话中只有**主机**能发起智能操作，插入后会向所有成员重新同步图表。

> 📄 **多页图表按当前页生效**：AI 只读取画布上正在看的那一页作为上下文，改动也只写回该页（其它页不受影响）；预览、确认或取消后画布仍停留在这一页，不会跳回第 1 页。

> ⚠️ 图表运行时（约 60MB）不随仓库分发，开发环境首次使用需先执行 `scripts/fetch-drawio-webapp.mjs` 获取。

## 八、专属文件（知识库 · 工作流 · Agent · 数据画布）

**专属文件**是本软件自己定义的文件类型：它们都有专属的处理模块或编辑器，在知识管理里新建、双击即用对应视图打开。四种类型分工如下：

| 文件 | 是什么 | 打开方式 |
|---|---|---|
| **`.kb` 知识库** | 由**知识处理**切片 / 向量化生成的可检索索引 | 双击跳到**知识处理**加载该库 |
| **`.flow.yml` 工作流** | 节点 + 连线的流程编排（可反复运行的固定流程） | 独立窗口里的**工作流画布** |
| **`.task` Agent脚手架** | 一个文件 = 一个可反复运行的批量 Agent 任务 | 独立窗口里的**脚手架视图** |
| **`.data` 数据画布** | 无代码数据建模：对象 + 字段 + 表单 + 图表 | 独立窗口里的**数据画布视图** |

### 8.1 知识库文件（`.kb`）

`.kb` 是**知识处理**把文档切片、向量化之后保存下来的**检索索引**（内容较多，所以单独成文件）。

- **怎么来**：在 [五、知识处理](#五知识处理) 里打开工作区 → 文件 → 切片 → 向量化 → 保存知识库。
- **怎么用**：双击 `.kb` 会**跳到知识处理**加载它（不是普通的文件视图），可检索、问答、重新切片；在主页的**知识库模式**里选择 `.kb` 即进入**检索 + 回答**；智能体预设开启**访问知识库**后会通过 `kb_search` 自动检索；[六、学习](#六学习) 模块也围绕 `.kb` 生成练习与复习内容。
- **在哪管**：一个 `.kb` 支持多个**版本**，工具栏可切换 / 保存；学习记录单独存在同目录的 `<库名>.learning` 里，不会写进 `.kb`。

### 8.2 工作流文件（`.flow.yml`）

工作流把**大模型、代码、网络请求、知识检索、文件处理**等步骤**拖拽连线**串成自动化流程，一键运行。它现在是**知识管理里的一种文件类型**：流程存成 `.flow.yml`（`.flow.yaml` 同样识别），在知识管理中打开即进入画布。

> 文件内容就是 **Dify 应用 DSL（YAML）**——可以直接被 Dify 导入，也能打开 Dify 导出的应用文件，因此画布上看到的结构与 Dify 一致。

#### 8.2.1 界面构成

打开 `.flow.yml` 后是三段式布局：

- **顶部工具栏**：添加节点 / 自动布局 / 运行 / 应用设置 / 删除选中 / 适应画布 / 保存；文件名后出现 ● 表示有未保存改动。
- **中间画布**：节点与连线，右下角是小地图与缩放控件，左上角会显示**问题**（例如未识别的节点类型）清单。节点卡片第二行显示该节点的关键配置（模型、输入 / 输出变量、迭代变量、文件等），容器节点显示在标题右侧。
- **右侧面板**：按需出现——**选中节点**时显示**属性面板**（编辑该节点），点工具栏**运行**时显示**运行面板**（点它右上角 ✕ 关闭）；两者不会同时显示，画布未选中节点时右侧不占位。

> 画布外观跟随**设置 → 界面**里的主题（深色 / 浅色与全部皮肤）：画布、节点卡片、连线、小地图、缩放控件、表单与滚动条都会一起适配。

#### 8.2.2 节点类型

**Dify 内置节点**

| 节点 | 用途 |
|---|---|
| **开始** | 工作流入口，定义输入变量（名称 / 类型 / 是否必填） |
| **结束** | 声明最终输出变量（变量名 + 取哪个上游输出） |
| **直接回复** | 把正文作为回复内容，正文里可用 `{{#节点.变量#}}` |
| **大语言模型** | 调用模型；可配多条提示词消息、上下文变量、温度与最大长度 |
| **智能体** | 选一个 AI-KM 智能体预设（角色提示词 / 工具能力 / 技能 / 知识库 / MCP）并给出任务输入，由它自主规划、调用工具完成任务；输出 `text` / `files` / `json`。Dify 的 `agent_strategy_*` 策略参数本地不执行（运行时会提示），改用预设的能力配置 |
| **条件分支** | 条件组按顺序判定（AND / OR），命中走对应分支，都不命中走 ELSE |
| **问题分类器** | 让模型把输入归到某个分类，每个分类一个分支 |
| **迭代** | 把数组逐项送进容器内的节点处理，结果汇总成数组；可设并发与出错处理 |
| **循环** | 按轮次重复容器内节点，可配循环变量与结束条件 |
| **代码执行** | 运行 Python 3，变量以赋值形式注入；定义 `main` 时自动调用并取其返回值（Dify 写法），否则代码打印 JSON 对象即输出变量 |
| **模板转换** | 用变量填充模板文本（`{{ 变量名 }}`） |
| **HTTP 请求** | 调用外部接口；地址、查询参数、请求头、请求体都支持变量模板 |
| **工具** | 通过 MCP 调用外部工具（Dify 插件类工具需 Dify 运行时） |
| **知识检索** | 从知识库检索相关片段；本地运行需在面板里指定 `.kb` 文件（该字段导出到 Dify 时被忽略） |
| **变量聚合** | 按顺序取第一个有值的变量 |
| **变量赋值** | 写入会话变量或容器循环变量 |
| **列表操作** | 过滤 → 排序 → 去重 → 提取字段 → 截断 |
| **参数提取器** | 让模型把自然语言抽成结构化参数（输出 `__is_success` / `__reason`） |
| **文档提取器** | 读取文件内容为文本（Word 会自动转成 Markdown） |

**本地扩展节点**（画布上带**本地**标签）

| 节点 | 用途 |
|---|---|
| **导出 Word** | 复用统一导出管线，把上游内容导出为 `.docx`（可选模板、目录、文件名、覆盖） |
| **本地数据表** | 读取 CSV / TSV / Excel；可选读取方式、最多行数、分批大小，输出 `rows` / `headers` / `total` / `batches` |
| **本地文件** | 完整文件模式输出 `content`；模板切片模式按正则切片，每片输出到各自的输出变量 |
| **本地知识库** | 直接绑定本地 `.kb` 文件检索，输出与**知识检索**一致 |
| **MCP 工具** | 内联填写 MCP 服务配置，或引用设置里已配置的服务 |
| **子工作流** | 调用另一个工作流文件：入参按变量名传入子流程的开始节点，出参取子流程结束节点的输出 |

#### 8.2.3 变量、分支与容器

- **变量选择器**：所有取值都用选择器（不写死节点名），按**上游节点输出 / 系统变量 / 环境变量 / 会话变量**分组。选中后显示为**节点标题 · 输出名**。
- **在文本里引用变量**：提示词、回复正文里可写 `{{#节点.变量#}}`，用选择器的**插入变量**直接插到光标处。
- **分支**：条件分支与问题分类器每个分支出一个端口（IF1 / ELSE、各分类名）；运行时只走命中的分支，其余分支在运行面板显示**已跳过**。
- **容器**：把节点**拖进容器框内**即成为它的子节点（拖出即解除）。容器会自动出现入口节点，迭代提供 `item` / `index`，循环提供 `index` 与循环变量；容器尺寸随子节点自适应。

#### 8.2.4 画布操作

| 操作 | 方法 |
|---|---|
| 选择节点 | 单击节点 |
| 移动节点 | 左键拖动 |
| 连线 | 从节点右侧端口拖到目标节点左侧端口 |
| 添加节点 | 工具栏**添加节点**在视口中心添加；或右键画布在点击位置添加；右键节点**添加下一步节点**加在其右侧并自动连线 |
| 复制节点 | 选中后 `Ctrl+D`，或右键**复制节点** |
| 删除 | 选中后 `Del`；或右键**删除节点**；连线选中后 `Del` |
| 平移 / 缩放 | 拖动空白处 / 滚轮，或右下角控件；**适应画布**一键铺满 |
| 自动布局 | 工具栏**自动布局**按层级重排 |
| 多选 | `Ctrl+A` 全选 |

> 连线会自动阻止自连、重复与成环，无效连线会给出提示。

#### 8.2.5 运行与查看结果

- 点工具栏**运行** → 填写**开始节点**声明的输入变量 → **开始运行**（运行中可中止）。
- **画布反馈**：节点右上角圆点表示状态——蓝=运行中、绿=成功、红=失败、灰=已跳过。
- **运行面板**：追踪树（容器子节点缩进显示）、每个节点的耗时与状态（展开可看流式输出与输出变量）、最终输出、运行日志。
- **运行历史**：面板顶部可切换最近 5 次运行，便于对比同一流程不同输入的差异。
- **单节点调试**：选中节点后可**试跑此节点**（只跑它，上游变量取缓存值）或**运行此节点及下游**（含本节点，上游不重跑）；也可以直接在运行面板的节点行上用 ▶ / ⇥ 触发。
- **变量检查器**：运行面板的**变量**区按节点列出跑出来的变量，可直接改值（对象 / 数组按 JSON 编辑，数字与布尔按原类型还原，格式错误就地提示）；改过的值标**已改**，可**单项恢复**或**全部恢复**；改完再重跑该节点或下游即可，无需重跑上游。变量缓存只存在内存里（不进文件）。
- **异常处理**：每个节点可选**出错即终止 / 忽略错误继续 / 移除异常输出 / 失败走异常分支**；大语言模型、智能体、HTTP 请求、代码与工具节点还可选失败用**默认值**继续（按输出变量名填 JSON 对象，失败时用该值继续往下跑），并支持失败重试与指数退避。
- **运行结果会随文件保存**：保存后重新打开仍能看到上次的节点状态（保存在节点的本地扩展字段里，导出到 Dify 时会被剥离）。

#### 8.2.6 应用设置（应用信息 / 功能 / 全局变量）

工具栏**应用设置**包含三个页签：

- **应用信息**：应用名称、说明、图标（emoji）、应用模式（工作流 / 对话流）。
- **功能设置**：开场白、推荐问题、允许上传文件与数量上限、引用知识库来源、敏感词过滤、语音转文字。
- **全局变量**：**环境变量**（不对外暴露的常量）与**会话变量**（跨轮次保留的状态），节点里可用**环境变量 · 名称**、**会话变量 · 名称**引用。

#### 8.2.7 保存、视图与兼容性

- **打开方式**：工作流是**知识管理中的一种文件类型**——在文件树里打开 `.flow.yml` / `.flow.yaml` 即进入画布；独立窗口打开时只有同一套画布。
- **保存**：工具栏**保存**或 `Ctrl+S` 写回文件并同步标签内容；文件名后的 ● 表示有未保存改动。
- **与 Dify 的关系**：文件本身就是 Dify 应用 DSL，导出即可在 Dify 导入；Dify 里未实现的节点类型会**原样保留**（画布上标为**未识别类型**），本地执行时会明确提示，不会被静默丢弃。
- **Dify 智能体节点**：本地按**AI-KM 智能体预设**执行（提示词 / 工具 / 技能 / 知识库 / MCP 都来自预设），Dify 的策略参数（`agent_strategy_*` / `agent_parameters`）原样保留但不生效。
- **本地扩展节点**：导出到 Dify 前建议先替换为 Dify 内置节点，或按需剥离。

### 8.3 Agent脚手架（`.task` 任务文件）

**Agent脚手架是通用 Agent 执行框架**（应用内称 Harness）：它按**表格驱动**的方式跑批量任务——一行一个任务，结果写回表格或汇总成数据表。一个 `.task` 文件就是一个独立任务，可中断续跑、后台继续；它复用你在设置里配置好的 AI 模型，**不需要额外配置命令行环境**。

- **怎么来**：知识管理文件树 / 文件视图右键 → **新建 → 脚手架**（写入空任务骨架），建好即在独立窗口里打开；已有的 `.task` 文件双击同样打开（同一个文件再次打开只聚焦已开的窗口）。
- **怎么用**：任务页左上**预设**下拉一键套用四种形态——**批量智能体运行 / 表格定向推理 / 文件采集表格 / 链接采集表格**；也可以手动组合**来源 × 执行方式 × 输出方式**三个维度（见 8.3.2），任务指令里用 `{{列名}}` 引用每一行的数据。
- **在哪管**：左列卡片顶部的**保存**写回**这个** `.task` 文件（**另存为**另存一份副本）；运行状态、进度与预计剩余时间显示在窗口底部状态栏。

> 2026-09 收尾：Agent脚手架模块只剩**一个脚手架——Agent脚手架**。原来的**批量智能体运行 / 表格定向推理 / 文件采集表格 / 链接采集表格**四个脚手架已改为它的**四种预设**；**数据画布**现为知识管理中的一种文件类型（`.data`，见 8.4）。旧的 `.task` 任务文件仍可双击打开，会提示**已并入 Agent脚手架**并自动转换为 Agent脚手架配置。
>
> 2026-10 起：脚手架**不再是顶部导航里的模块**，而是知识管理里的一种**文件类型（`.task`）**——一个 `.task` = 一个独立任务，双击即在**独立窗口**里用专属**脚手架**视图打开；原先的**实例导航栏与实例概念已取消**。

#### 8.3.1 打开与保存（一个 `.task` = 一个独立任务）

- **新建**：知识管理文件树 / 文件视图右键 →**新建 → 脚手架**（写入空任务骨架），建好即在独立窗口里打开；在任务页左上**预设**下拉选四种形态之一（批量智能体运行 / 表格定向推理 / 文件采集表格 / 链接采集表格），或保持**自定义配置**。
- **打开**：在知识管理里双击（或搜索、右键打开）任意 `.task` 文件，即在独立窗口里打开它的专属**脚手架**视图；同一个文件再次打开只会聚焦已开的窗口（不会重复开窗）。
- **保存**：任务页左列卡片顶部的**保存**把当前任务写回**这个** `.task` 文件（**另存为**另外存一份副本）；任务支持中断后续跑（状态保留），**重开该文件即可继续**。
- **随任务文件保留**：任务页左列**执行与配置**可分别勾选是否把 **图谱数据**（行过程快照，图谱与行详情的数据来源）与 **运行日志** 写进任务文件（重开后仍可查看）；默认两者都不保留（任务文件更小）。
- 运行状态、进度与预计剩余时间显示在窗口底部状态栏；任务文件里带所属类型标记，旧版没有标记的文件按内容特征识别；旧脚手架的批量 / 表格推理 / 文件采集 / 链接采集任务文件打开时**自动转换**为 Agent脚手架配置（见 8.3.3 末的兼容说明）；旧的画布 `.task` 文件会提示改名为 `.data`，再到**知识管理**里打开。
- 原**程序化工具调用**脚手架已下线（改为**内置PTC 智能体预设**），其旧 `.task` 文件打开时会提示迁移。

#### 8.3.2 Agent脚手架的配置方法（来源 × 执行方式 × 输出方式）

任务页把所有参数拆成三个维度，任意组合出不同工作流：

| 维度 | 选项 | 说明 |
|---|---|---|
| **来源** | 表格（导入 xlsx / csv） | 每行一个任务；导入后输入面板下方显示**来源路径**（附行数，悬停看全文） |
| | 文件夹（扫描本地文件） | 每文件一行（可选扩展名 / 排除目录），点**扫描文件夹生成任务行** |

> **文件夹来源的两个细节**：① 文件夹路径、扩展名与排除目录都随任务文件保存（重开该任务文件时会回填到输入框）；② 行数据不写进任务文件，而是在**打开任务时自动扫描该文件夹重建**（并把已保存的结果 / 状态按行合并回来）——所以选好目录就能直接关掉，下次打开会自动生成任务行。
| | 文本（每行一条） | 粘贴网址 / 文件路径 / 任意文本，点**按行生成任务行**，可设字段名 |
| **执行方式** | 智能体（完整会话，带工具） | 可读文件 / 联网 / 用知识库；可选智能体预设、最大步数、并发（上限 500）、重试、错峰等 |
| | 纯 LLM 推理（无工具） | 单次或分段调用，快且省；结构化提取与逐列写回都在这一侧 |
| **输出方式** | 单独结果 | 每行一个文本（相当于**只有一个字段**的结构化结果）：智能体→结果列；纯 LLM→逐列写回原表新列 |
| | 结构化提取 | 每行输出 JSON，按字段 / 主键合并进数据表（需**一行→多条**时可把**分段结果**改为每段各一条）；导出为新表 |

- **任务指令 + 数据选择**（输入面板）：任务指令含 `{{列名}}` 占位符、每行渲染一次（三种执行方式共用；旧**任务模板 / 任务目标 / 源列勾选**统一到这里）；**数据选择**点列名芯片即把 `{{列名}}` 写入 / 移除指令（已引用高亮，带全部引用 / 全部移除），未匹配占位符可勾选**保留原样**（默认清空）。
- **输出字段**（输出面板）：一张表同时承担**写回列**与**提取字段**——填字段名 + 推理指令 / 说明（结构化时另有**必填 / 主键**，主键用于合并去重）；切换输出方式不用重配。**输出方式 / 输出字段 / 导出列的说明文字改为在标题上悬停查看**，界面更紧凑。
- **内容获取**（结构化提取的素材来源，与**来源**正交）：直接使用行数据 / 读取字段中的本地文件 / 抓取字段中的网页（抓网页即链接采集：把页面标题与发现的链接存为行字段，按**链接跟随**在深度与页数约束内自动扩展新任务行）。
- **长内容分段与分段结果**：超过**分段大小**（默认 8000 字符）的内容会按段落 / 整行边界切成多段分别推理。默认**合并为一条记录**——把各段提取的片段按字段合并（文本字段按段顺序拼接、去重），**一个任务行（例：一个文件）最终只产出 1 条数据**；若文件里本来就含多条独立记录（长长的清单 / 列表页），把**输出 → 分段结果**改为**每段各成一条**。
- **源表改了怎么办（增量 / 同步源表）**：源表增删 / 改过行后，点**详情**页工具栏的**同步源表**（表格源重读表格文件，文件夹源重扫目录）——**不用重开任务**；重新导入同一个表格文件也会直接替换行（不再追加）。同步时历史结果会**按行指纹对回正确的行**（中间插行不会整表错位）；同时告诉你改了什么：**详情**页变化的行带 `新增` / `已变更` 角标（**已变更 = 还是同一行（首列标识一致）、结果仍留在该行上**，只是源数据改过、建议重跑），状态栏与工具栏显示**+新增 ~变更 -移除**摘要，点工具栏摘要里的**新增** / **变更**即可在下方表格里筛选（再点取消），悬停摘要可看**列级**差异（新增 / 丢失 / 顺序变化）与对位说明，筛选面板的**增量**可只看新增行或已变更行。被删掉的源行，其结果不再挂在任何行上（这些多余结果会**自动删除**，结果跟着源表走；只有对位不可靠——删掉的超过一半——时才只标**已移除**不删，结果页工具栏的**已移除 N**按钮可一键只看这些记录并逐条删除。同步 / 重新导入后当前轮次快照会立即重写，切轮次或保存用的都是同步后的结果。**结果条数多于任务行数是正常的**（结构化提取一行可产出多条记录），表下的统计会给出**一行多条 / 无对应任务行 / 已移除**各多少；工具栏的**异常 N**按钮可一键筛出不属于任何任务行的结果（行号缺失 / 超出当前行数，多为残留；筛出后点**删除这些**即可清掉，**清除**只是取消筛选）。若想让结果**完全等于**当前任务行的产出，用工具栏的**同步结果**：按任务行重建结果表（每个任务行只保留它自己产出的记录、行号与数据重新对齐，无主残留一并清掉））。结果表最左侧的**任务行**列点行号可直接跳到详情对应行。⚠ 指纹靠**一行原表列的值**算：若源表**列变了**（换过表 / 增删了列）或内容大面积对不上（换过表、行数差太多），指纹就不可比——此时会**按行号对位**（旧结果按原行号保留），并在日志与悬停提示里说明原因；增删位置**无法可靠确定**时（任务文件较旧、行被搬动、表内容变动很大）增量就**只报行数增减**，不硬猜是哪几行；判**已变更**用**归一化指纹**（数字千分位 / 多余小数点 / 前后空白 / 零宽字符等写法差异不算改动），任务文件是旧版（没存归一化指纹）时**不逐行判变更、只报增删**，重跑一轮后恢复。
- **结果与任务行是分开的（重跑会怎样）**：任务行（来源数据）+ 配置 = **任务**；跑出来的东西 = **结果**（每行结果 / 状态 / Token / 计时 / 过程快照，结构化提取另有一张数据表）。因此：① 结果页的**清除结果**只清结果、任务行与配置保留（行回到**待处理**可重跑）；② **重置**（任务页操作栏）才是连行数据一起清。重跑同一个行时：**逐列写回 / 单独结果** → 覆盖该行结果；**结构化提取** → 按输出 → **重跑结果**处理：默认**替换该行原有结果**（新结果写入前先删掉这条行上次产出的记录，重跑就是更新、跑失败则旧结果保留），选**保留并合并**则保留旧记录、配了**主键**就按主键更新原记录（完全相同则跳过），**没配主键则追加新记录**（适合多行汇总成一条）。结果页每条记录的**最右侧有删除图标**，可单独删掉这一条（结构化提取会同步移除它写回原表的数据，该行回到可重跑状态）。
- **多轮处理（轮次）**：任务页**轮次**可选 / 新建 / 重命名 / 删除运行轮次——新建轮次会**保留同批任务行**（状态全部置回待处理）并沿用当前配置快照，可换配置或指令再跑一轮；每轮各存一份配置与结果，切换即载入该轮（结果 / 图谱 / 导出都只针对当前轮），任务文件按轮次分槽保存（旧文件自动作为第 1 轮）。
- **跨轮引用与对比导出**：**数据选择**里的**前轮结果**芯片（如 `{{第1轮.结果}}`、`{{第1轮.简介}}`）可把前几轮产出写进本轮指令——取的是**同一行**在该轮的结果 / 字段值（逐轮打磨、复核很有用）；**输出 → 导出列**里可勾选任意轮次，导出时把各轮结果按行**并排成列**，一眼对比差异。
- **链式轮次与对比视图**：轮次区带 **⑂** 的按钮是链式新轮次——把本轮的结果展开成新一轮的任务行（结构化提取按记录逐条展开，行数据带 `_源行` 标注来源），适合**先发散再收敛**的流程；多轮时会出现**对比**页签，把同一批行在各轮的产出并排展示（⚠ 各轮不一致 / ? 有轮次缺结果；上方**轮次**芯片可点选显示 / 隐藏该轮，**至少保留一轮**）；**点任意一格的产出**即可弹窗用 Markdown 渲染预览，标题显示所属轮次。对比表始终列出**全部行**——只在其它轮出现的行也会列出，缺结果的格显示 `—`。跨轮引用按**原始行号**对齐，因此链式展开后仍能取到同一来源行的前轮结果。
- **行详情三页签**：点表格任意一行弹出详情，分 **任务 / 过程 / 输出** 三个页签——任务 = 占位符替换后真正发给该行的任务，过程 = 推理步骤与工具调用（**默认只显示单行摘要**，点一下展开参数与结果，与主页对话的工具盒子同款；运行中实时更新），输出 = 提取数据 / 写回列 / 结果文本（**运行中直接流式显示渲染后的正文**，不再显示 Markdown 源码；Markdown 按预览尺寸紧凑排版）。页签在左、运行计数（开始 / 结束 / 耗时 / 步数 / Token）在右；**页签选择会保持**，切换行时不必重新点一遍。**底部按钮栏**从左到右：页签对应的操作（任务页 = 复制替换后的任务；输出页 = 编辑，编辑中变**保存 / 取消**）→ **状态下拉**（待处理 / 已完成 / 失败 / 跳过，**只改状态、不动结果**——选**待处理**= 待执行，回**任务**页点启动就跑它，重跑等价于**置待处理 + 启动**，也可用筛选面板的**重跑命中行**立即执行；执行中的行状态不可改）→ **停止本行**（仅该行执行中显示：取消它的会话或请求，之后标记为**跳过**，**其它行与整批继续跑**）→ **重跑本行**（不是执行中时显示：批量运行中插到队首立即执行；**未运行时只跑这一行**，其它待处理行不动——日志会提示还有多少行未纳入本次执行）→ 删除；最右侧是关闭。按钮与下拉高度一致；**详情表格的操作列只显示状态文字**，按钮全部收进这个面板。
- **筛选面板（含步数 / 耗时筛选与批量标记）**：详情页左上的**筛选**按钮打开面板，把 **状态 / 搜索 / 结果或指定字段 / 行号 / 步数 / 耗时** 集中在一处——步数与耗时用 `< ≤ > ≥ =` + 数值：未运行 / 无步数按 **0 步**、无起止时间按 **0 秒** 计，耗时默认单位为秒，也可写 `90`、`1.5m`、`2m30s`、`1h`；**字段**一行先选列（默认**结果**列，也可选具体的**提取字段**或**原表列**，含逐列写回的新列），再填关键字（多个用 `|` 分隔，命中任一即显示）；右侧**为空**开关 = 快速筛出该列为空的行（等价于写 `|''`）。面板内实时显示 **命中行数**（按钮上也带**条件数 · 命中/总数**），并列出当前生效的条件。命中行可一键 **批量标记** 为 待处理 / 跳过 / 已完成 / 失败（只改状态、不动结果——**待处理**= 待执行，下次点启动就会跑），或点**重跑命中行**立即执行（批量运行中插入优先队列，未运行则标记待处理并马上启动）。执行中的行不参与标记与重跑。导入表格与重置在**任务**页。
- **导入大表格的进度**：导入（或打开任务文件后自动读取源表格）时，**底部状态栏最左侧**会显示**读取表格 x/y 行**并带转圈，**每 5000 行刷新一次**；导入完成后状态栏左侧会提示**已导入 N 行**（失败则提示导入失败，详情在日志里）。
- **导出列**：**输出 → 导出列**是一个**竖向列表**：**原表列**、**运行信息列**（行号 / 任务指令 / 状态 / 错误 / Token / 起止时间 / 耗时 / 步数 / 重试 / 原始输出）与**各轮结果**都在同一个列表里——点一下开关即选中 / 取消，按住左侧手柄上下拖动可调整顺序（**列表顺序就是导出表的列顺序**），**点列名可直接改名**（回车 / 失焦生效，留空恢复默认；结果页表头与导出的 Excel 都用这个名字；改过名的列会标出原名，结果页表头悬停也能看到原名），每项右侧标注来源；把**输入表 + 输出表**合成一张表；未做选择时按旧行为导出。其中**原始输出**= 该行模型的原始回答（结构化提取模式下模型没返回合法 JSON 时也有内容），勾选后记录行也会带上原文；**若存在没解析出结构化数据的行，导出会自动补上该列**（只填这些行），保证内容不会被默默丢掉。结果页即**导出预览**（与导出内容一致；滚动到底会自动继续加载，每批 200 行）。**导出大表分片写入**（每 2000 行一片，片间让出界面）：不会卡住，且**状态栏显示导出 x/y 行进度**，导出期间按钮显示**导出中…**。
- **随任务文件保留**（左列**执行与配置**）：勾选 **图谱数据**（行过程快照——图谱与行详情的数据来源）与 / 或 **运行日志**（主日志 + 各线程日志），保存任务文件时一并写入，重开后无需重跑仍可查看图谱与日志（表格任务导入原表格后按行自动合并）；**默认两者都不保留**（任务文件更小）。每行的 **推理步数** 只是一个数字，**始终随任务文件保存**，重开后**步数**列、步数筛选与导出照常可用。
- **标签页**：任务（配置与启动）/ 详情（每行一个子任务：状态、起止时间、耗时、推理步数、Token（**纯 LLM 推理同样统计行 Token**）、错误；结构化提取按**输出字段**逐列展示，点行看完整记录）/ 结果（导出预览与**导出 Excel**；**渐进式加载**，支持全列关键字搜索、按列筛选与行号跳转高亮，并可逐条删除结果；最左**任务行**列可跳到详情对应行）/ 图谱（链接采集的**爬取轨迹**；任意智能体行的**访问路径**——每行一个**智能体**节点（紫），连向它访问过的信源（网页 / 文件 / 搜索 / 知识库）与调用过的 MCP 服务（没有调用工具的智能体也会显示为单个节点）；工具栏用**彩色圆点图例**展示各类型，**单击圆点即可筛选**显示 / 隐藏该类型（图例悬停看数量），节点上限可调（默认 2000）；新增节点从视口外侧移入；打开图谱时先给一个较广的初始视角，**布局收敛后自动把全部节点框进视口并居中**（自己缩放 / 拖动后不再自动调整）；不需要图谱时可在**执行与配置**取消勾选 **启用图谱标签页**（关闭后不做投影、也不显示该页签），默认视图按任务自动选择（有网页行 → 爬取轨迹，否则有过程快照 → 访问路径），无内容时给出说明）/ 日志（左侧导航栏纵向列出主日志与各线程、级别筛选）/ 帮助。
- **续跑与重跑**：**启动**只跑当前待处理行（标记为待处理的行也算待执行，下次点启动就会跑）；中断后可保存 / 读取状态续跑；重跑对象 = 当前筛选命中行——在**详情**页的筛选面板里点**重跑命中行**（批量运行中会插入优先队列立即执行，未运行时标记待处理并马上启动，不会带跑其它待处理行）。**运行状态只在底部状态栏最左侧显示**（转圈 + **执行中…**等状态文字），左列**启动**按钮运行时只变灰、不再显示**运行中…**。

#### 8.3.3 四种预设（原四种脚手架）

任务页左上**预设**下拉一键套用（自动联动 来源 / 执行方式 / 输出方式与参数，已导入的任务行保留；手动改动任一维度后回到**自定义配置**）：

| 预设 | 形态（源 × 执行 × 输出） | 适用 / 说明 |
|---|---|---|
| **批量智能体运行** | 表格 × 智能体 × 单独结果 | 每行交给一个独立智能体（含工具）并发执行——批量写作 / 分析 / 生成；可筛选、批量重跑、导出 Excel |
| **表格定向推理** | 表格 × 纯 LLM × 结构化提取 | **输出字段**逐列配置推理指令（可留空 → 按字段名自动分析），逐行推理——批量打标签、补全字段、风险评级；结果进数据表、导出为新表 |
| **文件采集表格** | 文件夹 × 结构化提取 | 扫描本地文件逐文件提取字段，按主键合并成数据表——从大量文档中整理清单 |
| **链接采集表格** | 文本（网址）× 抓取网页 × 结构化提取 | 逐页抓取 + 链接跟随扩展任务行——采集网站上的结构化信息；图谱页看爬取轨迹 |

> **兼容旧任务文件**：**读取任务状态**或双击旧 `.task` 时按类型自动转换——批量智能体（同构直接读）、表格定向推理（→ 结构化提取：原**目标列**= 输出字段、**源列**勾选 → 任务指令、旧写回值 → 数据表记录）、文件采集（文件夹 / 扩展名 / 字段 / 已采集数据恢复）、链接采集（网址行 / 深度 / 跟随关键词 / 已采集数据恢复）；旧文件没有 `scaffold` 标记时按特征键识别。

### 8.4 数据画布（`.data` 文件）

**数据画布是无代码数据建模**：在画布上用节点与连线搭出**表格 / 参数 / 图表 / 子画布**等结构，再用表单录入数据、用图表看结果——不写 SQL 或脚本，就能把一批数据「建好结构、录进去、看到图」。

- **怎么来**：知识管理文件树顶部 ➕ 创建文件 → 类型选**数据画布**（生成 `.data`），或在文件树 / 文件视图右键 → 新建 → 数据画布；新建后是**空画布**，可直接建模。
- **怎么用**：在知识管理里打开 `.data`（**浏览 / 可视编辑**视图即画布模块，自带**主页 / 数据 / 画布 / 帮助**四个子标签）：**画布**页摆节点与连线、**数据**页按列配置录入方式并逐条录入、**主页**页看图表看板。
- **在哪管**：改动约 1.5 秒防抖**自动保存**回它自己的 `.data` 文件（工具栏 💾 可立即保存）；**源码编辑**视图里看到的就是 JSON，可以直接改。

> 数据画布**已不再是顶层模块**（导航里没有数据画布入口），它现在是知识管理里的一种文件类型 `.data`；旧的画布 `.task` 文件改名成 `.data` 放进工作区即可继续编辑（见 8.4.1 的迁移说明）。

#### 8.4.1 `.data` 画布文件：在知识管理中编辑

- **文件类型**：`.data` 就是画布文件（内容形如 `{ models, activeModelId }`）。在知识管理里打开它：**浏览**与**可视编辑**视图都渲染数据画布模块（模块自带 **主页 / 数据 / 画布 / 帮助** 四个子标签），**源码编辑**视图显示 **JSON 文本**，可直接改数据。
- **创建**：知识管理文件树顶部 **➕ 创建文件** 的类型里选 **数据画布**（生成 `.data`），文件树 / 文件视图右键**新建 → 数据画布**也有该类型；新建的 `.data` 打开后是**空画布**（无内容，可直接建模）。
- **保存**：画布内容变更后约 **1.5 秒防抖自动保存**回它自己的 `.data` 文件，工具栏 💾 也可**手动保存**；保存后已打开的标签内容同步（切到源码编辑立刻能看到新 JSON），其它窗口 / 标签也会被通知刷新。
- **切换文件**：切换标签时未保存的改动会**先静默写回原文件**，再载入新文件；新文件为空时画布**清空**（不会残留上一个文件的内容）。关闭标签 / 离开知识管理时同样会先写回。
- **独立窗口**：文件右键 → **打开** → 选视图，独立窗口里**固定为画布**（没有视图切换器）；要改 JSON 请在知识管理里切到**源码编辑**。`.data` 已注册**系统文件关联**，双击 `.data` 会用本应用打开。
- **两种用法**：`.data` 既可作画布文件打开编辑，也可用画布工具栏**导出**得到 **`.data` 数据包**、或把 `.data` **拖进画布**作为**子画布节点**导入——两者内容同构。
- **从旧 `.task` 迁移**：画布**不再**从 `.task` 打开。双击旧的画布 `.task` 文件（内容含 `models`、`scaffold: 'canvas'`，通常在 `%APPDATA%\knowledge\tasks\`，例如 `数据画布-2.task`）会弹提示**画布文件已改用 .data 扩展名**——把该文件**改名为 `.data` 并放进工作区**，即可在**知识管理**里继续当作画布编辑（内容形状同构，改名即可打开）。
- **窄面板适配**：分屏或窗口很窄时，画布顶栏会自动**换行**，右侧按钮不再被裁掉。

- **画布**标签：从左侧**节点**面板放置 6 种节点（参数 / 数据表 / 子画布 / SQL / 变量 / 图表），连线建立数据流，点**计算**查看结果。
- **录入**标签：按节点页签录入参数 / 表格数据；数据表节点可开启**表单录入**（为每列配置录入方式：文本 / 多行 / 数字 / 日期 / 下拉 / 开关），支持添加行、导入 Excel。
- **看板**标签：自动展示所有图表（柱/折/饼图、地图），可全屏。
- 支持导出 / 导入 `.data` 文件备份迁移。
- 典型场景：多单位统计汇总后的**成本测算与辅助决策**（填报 → 汇总建模 → 图表看板对比取舍）、项目成本台账、科研实验数据记录与对比、轻量业务台账（替代分散的 Excel）。

## 九、浏览器

浏览器是一个**独立窗口的内置网页浏览器**（与知识管理分开），从导航栏右侧的地球图标打开。它除了能像普通浏览器一样看网页，更关键的是**能被 AI 直接操作**——智能体可以在其中打开网页、抓取正文、填写表单与点击，把网页变成可被 AI 使用的信息源。

### 9.1 界面与基本浏览

- 顶部是**多标签**栏与地址栏：输入网址或搜索关键词回车即可；标签可拖拽排序、点 ✕ 关闭，➕ 新建标签。
- 右侧是**设置停靠栏**：查看当前标签的 AI 状态（浏览 / AI / 操作中），并可执行**在系统浏览器打开 / 保存整页 / 回收 AI 会话标签 / 打开控制台 / 允许执行 JS / 清理缓存**。
- **浏览器设置**里有**默认页面**（手动打开时首个标签加载，AI 调用不受影响）与**保存文件夹**（书签与离线页的落盘目录，留空 = 当前工作区根目录）。

### 9.2 能力一览

| 能力 | 说明 |
|---|---|
| **多标签浏览** | 标签可拖拽排序、悬浮关闭；地址栏支持网址与关键词，带自动补全与加载状态 |
| **AI 会话标签** | 智能体打开网页时使用带机器人标记的标签，与你的手动标签区分；空闲后自动回收，点一下即可接管保留 |
| **收藏书签** | ⭐ 收藏常用页面，书签落盘到**保存文件夹**，书签面板可快速打开 / 编辑 / 删除 |
| **离线保存整页** | 把当前页（含图片、样式等资源）整体保存为离线 HTML，便于归档与后续阅读 |
| **本地网页渲染** | 知识管理中的 `.html` / `.htm` 默认用内置浏览器打开渲染，AI 可继续操作与提取正文；要看文件视图预览或改源码，走右键**打开 → 选对应视图** |

### 9.3 让 AI 操作网页

1. 直接在对话里提需求，例如**打开某页面并摘取要点**、**把这个表单填好**。
2. 智能体会自动调起浏览器，在 **AI 会话标签**中打开页面、读取正文、点击或输入。
3. 结果（正文 / 摘要 / 截图）会带回对话继续推理（截图以**压缩后的 JPEG** 返回，避免一张大图挤爆模型上下文）。

浏览器 Agent 同时是**内置 MCP 服务 `builtin-browser`**：智能体通过 `browser_*` 工具导航、新建 / 切换 / 关闭标签、读取正文（文本 / Markdown / HTML）、点击、输入、滚动与截图，可在 **设置 → 工具 → MCP** 中开关与查看函数清单。

### 9.4 使用要点

- 出于安全考虑，**允许 AI 执行 JS**（`browser_eval`）**默认关闭**，需要时在右侧设置栏按需开启。
- AI 会话标签会**空闲自动回收**以免堆积；想保留某个页面就点一下该标签。
- 缓存大小可在右侧设置栏底部查看并一键清理。
- 设置页里的**官方文档 / 申请入口**等外链也用内置浏览器打开，不会跳系统默认浏览器。

## 十、插件（Plugins）

本地插件机制：插件可以给智能体**新增工具**，也可以**往界面里加面板 / 设置卡片**、注册**全局快捷键**与中英文案，用来把自己写的脚本 / 团队内部工具接进 AI-KM。

- **插件能加到界面里的位置**：① **主面板**（注册后自动出现在导航栏，与**主页 / 知识管理**一样可切换、可在功能开关里隐藏）；② **设置页签**（归入设置左侧的**插件**分组）；③ **设置卡片**（插进任意已有设置页）；④ **集群工作台页签**（追加在**通信**之后）。插件停用 / 卸载后这些界面元素**立即消失**，正停在插件面板上时会自动切回**主页**。
- **插件能调用的宿主能力**：`ctx.llm`（按来源 / 模型发起对话）、`ctx.files`（选文件 / 读文本 / 读表格 / 读二进制 / 用内置查看器打开）、`ctx.app.agentPresets()`（读取 Agent 预设清单）等；另有全局快捷键、中英文案字典、主动通知与自己的配置存储。
- **插件出问题不会连累主界面**：单个插件的界面崩溃会就地显示**扩展出错了** + 重试按钮，其余部分照常使用。

> ⚠️ **插件与主进程同进程运行（界面部分与主界面在同一页面），不受工作区沙箱保护**：只启用你信任的插件；权限声明只用于透明化与误操作防护。

下面按**管理 / 商店 / 开发**三块说明。

### 10.1 管理（插件管理）

- **插件目录**：标题栏显示当前目录，右侧文件夹图标可直接打开。默认 `<用户数据>/plugins`；点**选择插件目录**可改到自己的文件夹（和技能一样），点**恢复默认插件目录**还原。切换目录后会重新扫描该目录下的插件。把插件包（`package.json` 里带 `aikm` 清单字段）放进目录，重启或点**重新扫描**（🔍+）即被发现；目录内文件改动会**自动重载**。仓库 `examples/plugins/hello-panel` 是可直接复制的示例插件（工具 + 界面 + 快捷键 + 双语示例）。标题旁的 ⚠️ 图标悬停可看**安全提示**（插件以宿主权限运行、不受工作区沙箱保护）。
- **分文件夹存放**：插件可以直接放在插件目录下，也可以按用途放进各级子文件夹（如 `plugins/办公/表格工具/`）。扫描会递归到**第 4 层**并自动跳过隐藏目录与 `node_modules`；列表里每个插件的名称后会显示它**属于哪个文件夹**（顶层插件显示**根目录**），详情里另有完整相对路径。**新写的插件会自动发现**：文件夹放进去约 1 秒内就会自动装载并出现在界面上（不必重启，也不必手动扫描；目录被删除时列表里也会自动消失）；目录栏的**重新扫描**保留为兜底手段。同名插件出现在不同文件夹时只认最外层那一个。
  - ⚠️ **目录名必须是合法插件 id**：以字母 / 数字开头、只含 `[a-z0-9._-]`（= 清单 `aikm.id`）。名字里带**中文 / 大写 / 空格**的插件文件夹会被宿主**整目录跳过**（插件不会出现在列表里），此时目录栏下方会给出提示并列出被跳过的文件夹，改名后自动恢复。
- **从文件夹安装**：点 ➕ 选择插件包文件夹，自动复制进插件目录（跳过 `node_modules` / `.git`）；若已存在同名插件会询问是否**覆盖安装**。
- **搜索过滤**：标题栏下方是搜索框，按**名称 / 插件 id / 文件夹 / 申请的权限 / 工具 / 服务 / 描述 / 状态**任一命中即显示（例如输入 `net` 只看要联网的插件、输入 `办公` 只看某个文件夹下的插件），右侧 ✕ 一键清空；计数会显示「匹配数 / 总数」。
- **列表信息**：版本、要求的宿主 API 版本、状态（已激活 / 等待依赖 / 加载失败 / 已禁用）、**申请的权限**、注册的工具与对外提供的服务、**数据占用**（有数据时在名称旁显示大小）；加载失败会显示具体原因（只影响该插件本身）。
- **数据管理**：每条插件的 🗄️ 按钮打开数据面板——显示该插件合计占用与三处位置（设置存 localStorage 的 `aikm.plugin.<插件 id>.*`、存档等大文件存本机 OPFS 的 `plugins/<插件 id>/`、插件私有数据存主进程的 `plugins-data/<插件 id>/`），并列出每一项的名称与大小，可**逐项删除**（每行右侧 ✕）或**一键清除全部**（都有确认框）；面板底部另有**刷新**。清理只删该插件自己的数据，不会动插件本体文件（删本体请用**移除**）。
- **操作**：启用 / 禁用 / 重载（先撤销旧注册再重新执行）/ 日志 / 配置（传给插件的 JSON 配置，保存后点重载生效）/ 详情 / 移除——每条插件**标题行右侧**是一排**图标按钮**，鼠标悬停显示该操作的说明（描述文字因此可以占满整行宽度）。重载会**连界面半边一起重新装载**（改完插件的界面代码不必重启软件）；界面半边装载失败时，卡片上会直接标出**界面半边装载失败**并给出原因，点**重载**即可重试。
- **详情**：一次看清标识与版本、状态、权限（每个权限都有一行说明）、工具、服务、**已在界面里占用的位置**（主面板 / 设置页签 / 设置卡片 / 工作台页签，按 owner 归属）、**该插件注册的快捷键**（含说明）、当前配置、插件目录与入口文件路径。
- **移除**：默认只从列表移除并保留磁盘文件；确认框里会再问一次是否**连磁盘文件一起删除**（不可恢复）。
- 启用等变更操作会先弹出确认框并列出该插件申请的权限。
- **权限**：`fs`（文件读写；带此权限的插件工具默认需要审批）、`shell`（执行命令，且仍受 trusted 策略约束）、`net`（网络请求）、`agent`（只读会话日志）、`llm`（调用你在**设置 → 模型**里配置的来源与模型，会消耗额度 / 算力）。未申请的权限一律拒绝。
- **智能体如何使用插件工具**：插件工具注册在 `plugin:插件id` 作用域下，已启用插件的工具会自动加入智能体的可用工具集（可在预设**工具**页按需关闭；停用插件后工具立即消失），不会与内置工具重名（重名会直接报错）。

### 10.2 商店（从共享目录安装）

把**协作 → 共享**里共享的文件夹直接当插件来源 —— 粘贴那条 `remote-fs://<ip>:<port>?token=…` 地址（或点**本机共享目录**），商店会自动扫描出其中的插件与技能并支持一键安装；安装前会列出该插件申请的权限并要求确认。把插件 / 技能文件夹放进共享目录即可发布（可分类放进子文件夹，最多 4 层），由软件实时生成清单，**不需要手写索引文件**；同一地址也能在**技能 → 商店**里加成来源。技术上复用的是共享服务已有的只读 HTTP 接口（`/fs/store` 清单、`/fs/bundle` 目录打包，都需要令牌），没有引入 FTP 等新协议与新端口。

### 10.3 开发（写插件的起点）

> ⚠️ **命名规则（先定好，避免返工）**：插件**文件夹名必须等于清单里的 `aikm.id`，且只能用 ASCII 小写 `[a-z0-9._-]`**（以字母 / 数字开头，如 `my-plugin`）。文件夹名带**中文 / 大写 / 空格**时宿主会**整目录跳过**——插件根本不会出现在列表里（管理页会给提示，但不能只靠它发现）；改一次名就要重写清单，所以先定英文目录名。中文写进清单的 `aikm.name`（显示名）与界面文案即可；插件的工具名同样要蛇形 ASCII（`my_tool_action`）。这条规则在**通用开发指令**、**各个模板**、**硬约束**以及内置 MCP 服务的 `plugin_dev_host` / `plugin_dev_constraints` 里都会**先说明**，智能体不会到交付前才发现。

- 一句话说明：**把页面里的通用开发指令整段复制给任意大模型 + 写清你要的功能**，它产出的文件放进插件目录，就能在**管理**里启用——不需要看源码。也可以**不复制任何东西**：聊天里选**插件开发智能体**，它已绑定内置 MCP 服务 `builtin-plugin-dev`，该服务按主题拆成 6 个短工具（插件目录 / 硬性约束 / 清单字段 / 宿主 API + 最小示例 / 报错对照 / 模板与安装步骤）外加 1 个**自检工具 `plugin_dev_check`**——写完插件后智能体会自己跑自检，拿到**宿主真实的加载状态与日志（含界面半边装载失败的原因）**并修到没有 ✗ 才交付；直接问它**做一个 xx 插件**即可（不会再满盘搜索软件源码）。这个服务也能给其它智能体与外部 MCP 客户端用。
- 页面内容：① **如何使用插件**（安装 → 启用确认权限 → 面板 / 工具 / 快捷键在哪看 → 配置 → 排障 → 卸载，可一键复制）；② **从零开始的最小插件**（目录 + `package.json` + `client.mjs` 全文，照抄即可跑）；③ **可复制的指令模板**：通用开发指令、界面插件（面板 + 设置页签 + 快捷键）、**设置页签 / 设置卡片（把配置项放进「设置 → 插件」，含设置分组与设置页 id 清单、完整设置组件骨架）**、**图表面板（canvas 饼图 / 柱状图，含数据变化后重画的正确写法）**、工具插件（给智能体加工具）、大模型 / 文件能力插件，以及**排障指令**（把**管理 → 日志**里的报错和代码一起粘给模型，让它给完整可替换的文件）；④ **清单 / 槽位 / API 速查表**（`aikm` 清单字段、五个权限、五个内置槽位、界面与主进程两套 `ctx` 方法、硬约束）；⑤ **常见问题**（装载失败、槽位未声明、权限报错、设置页签跑到别的分组 / 卡片出现在所有设置页、深色主题白底白字、面板被挤扁 / 撑大窗口、图表 canvas 不显示、提示显示 `[object Object]`、改动何时生效）。
- 每个指令块右上角都有**复制按钮**（复制成功会提示**已复制，粘贴给大模型即可**）。

**插件能加到界面里的位置**：① **主面板**（注册后自动出现在导航栏，与**主页 / 知识管理**一样可切换、可在功能开关里隐藏、顶栏标题自动显示；内容超过窗口高度时面板内部滚动）；② **设置页签**（归入设置左侧的**插件**分组）；③ **设置卡片**（插进任意已有设置页，需在注册时声明目标页面）；④ **集群工作台页签**（追加在**通信**之后）。插件停用 / 卸载后这些界面元素**立即消失**；若当时正停在插件面板上，主导航会自动切回**主页**。

**插件能调用的宿主能力**（常用）：

- **大模型**：`ctx.llm.chat()` 按来源 / 模型发起一次对话，`ctx.llm.sources()` / `ctx.llm.models()` 列出配置过的来源与模型清单（面板里可以让用户选来源 / 模型）——需 `llm` 权限。

- **应用信息**：`ctx.app.agentPresets()` 读取**设置 → 智能体 → 预设**清单，插件可让用户选一个预设当角色（如合同审核）。

**其它插件能力**：注册**全局快捷键**（冲突时给出提示，输入框内不触发）、提供**中英文案字典**（跟随界面语言切换）、主动弹**通知**，以及读写自己的配置。

- **插件出问题不会连累主界面**：单个插件的界面崩溃会就地显示**扩展出错了**+ 重试按钮，其余部分照常使用。
- ⚠️ **插件与主进程同进程运行（界面部分与主界面在同一页面），不受工作区沙箱保护**：只启用你信任的插件；插件代码能做到宿主能做的任何事，权限声明只用于透明化与误操作防护。

### 11.2 模型（Models）

> 模型是设置里的**一级分组**，下分 **来源**（各来源的连接配置）/ **嵌入**（嵌入兜底）/ **凭据**（API 密钥）三页。
> ⚠️ 左侧来源列表**点一下只是查看 / 编辑该来源，不会把默认来源换过去**；要让主页 / 知识库 / 工作流默认用它，需在页头点**设为默认**。默认来源在列表里带**默认**标识。

**来源（Sources）— 最关键的一页**：

顶部选择 **AI 类型**，共 9 种：`Ollama / LM Studio / DeepSeek（Chat / Responses 接口样式）/ GPUStack / OpenAI / Anthropic / Google / Azure / 自定义来源`（DeepSeek 只有一个来源，Chat Completions 与 Responses API 用**接口样式**切换）。每种类型都有**API 密钥或凭据引用**两种填法（见 11.1 凭据）。

- **来源启停**：左侧来源列表中每一项右侧都有开关，可停用不用的来源（停用后主页 / 预设 / 工作流 / 集群的来源下拉不再出现）。
- **多个自定义来源**：可添加多个**自定义来源**（每个有自己的名称、地址、密钥与模型），侧栏可切换当前激活来源；主页聊天可**按对话单独绑定**某个自定义来源，工作流节点也能指定具体来源。
- **刷新入口就一个**：各来源配置块里不再为模型列表 / 加载状态 / 上下文窗口各配一个刷新按钮，而是**统一用块底部的API 状态（自定义来源为连接测试）**：点一次 = 测试连通性 + 回填可用模型 + 刷新加载状态（Ollama / LM Studio）+ 重新探测上下文窗口。
- **Ollama 模型明细与加载状态**：结构同 LM Studio——网格列出本地**全部模型**：**类型**（对话 / 视觉 / 嵌入，取自 `/api/show` 的 capabilities）、**生效上下文**（已加载显示实测生效值，未加载显示 Modelfile 的 `num_ctx`）与**模型上限**对照、**是否已加载**；悬停可看 family / 参数规模 / 量化 / 体积 / 能力 / 嵌入维度 / 驻留到期时间。每行右侧的 ⬇ / ⏏ 可直接**加载 / 卸载**（加载走 `/api/generate` 的 `keep_alive`，嵌入模型自动改用 `/api/embed`；卸载 = `keep_alive 0`）；**加载后保持**可填 `30m`、`2h`、`-1`（常驻）。**默认嵌入模型**下拉只列嵌入模型（能力已知时过滤），选到非嵌入模型会直接提示。
- **LM Studio 模型加载状态 / 一键加载卸载**：LM Studio 来源的配置块里会列出 LM Studio 里的**全部模型**（网格逐列对齐，不限高度）：**类型**（对话 / 视觉 / 嵌入）、**是否已加载**，已加载的行显示**设置 X**= **LM Studio 里设置的、当前实际生效的上下文长度**（取自 `lms ps`，不是模型能力上限），未加载的行只能显示**上限 X**（此时读不到设置值）。每行右侧的 ⬇ / ⏏ 可直接**加载 / 卸载**（走 LM Studio 官方 `lms` 命令：加载前可填**加载时上下文长度**，留空 = LM Studio 默认；大模型加载需数分钟，完成后自动刷新状态）。面板顶部还会显示当前所选模型的**LM Studio 设置值 / 模型上限**；**默认嵌入模型**下拉只列**嵌入模型**（已按 LM Studio 返回的类型过滤）。默认嵌入模型未加载或不在列表中会直接提示（否则知识库问答会报 `No models loaded`）。若提示未检测到 `lms` 命令，可在 LM Studio 的 Developer 页安装 CLI 后点一次**API 状态**。

**上下文窗口（只读信息）**：除 **Ollama / LM Studio**（它们的窗口已在**模型加载状态**面板按模型列出：生效 / 默认 / 上限）外，其余来源配置块底部有一行**上下文窗口**显示圆环实际使用的分母；如需重新探测，在该块底部的**API 状态**点一次即可。另有**窗口上限覆盖**行——**仅在历史上设置过覆盖值时才会出现**，届时可点 ✕ 清除回到自动。两行都不可编辑，判定依据写在悬停提示里；优先级说明见 3.8。

**通用参数**（所有类型共用）：温度（0–2，滑块，默认 0.7）、最大令牌数（100–30000）、**流式响应**开关。

底部：**连接状态**（已连接 / 未连接）+ 🔌 **测试连接**、🔄 **刷新**。测试通过（绿色**已连接**）即可使用。

> 💡 **本地模型推荐**：下载安装 [Ollama](https://ollama.com/)，运行 `ollama serve` 和 `ollama pull qwen3`，再在软件里选 Ollama 类型刷新模型即可，**无需任何 API Key**。

**嵌入（用于兜底嵌入）**：

- **嵌入兜底**：当前来源不提供嵌入接口（如 DeepSeek / Anthropic）时，知识库建库与检索的向量化改用这里选的来源（下拉列出已启用来源，自定义来源逐个列出）。
- **兜底嵌入模型**：选该来源的具体嵌入模型（可点**刷新**拉取模型列表）；**留空 = 用该来源的默认嵌入模型**（下方提示会写出实际取值，如 `nomic-embed-text`）。
- 各来源自己的**默认嵌入模型**（该来源自身做向量化时用哪个）仍在**模型 → 来源**页对应来源配置块里选。

**凭据（Credentials）**：集中管理 API 密钥，**明文只存主进程**（credentials.json），界面仅显示脱敏值。

- 以**表格**展示：名称 / API Key（脱敏）/ 更新时间 / 操作。
- 新增：在末行输入**名称**后回车即跳到密钥输入框，**密钥**再回车即保存；同名保存即**覆盖**密钥。行内的 ✏ 按钮可把已有名称填入新增行便于修改。
- 用途：来源页每个来源的**凭据引用**输入框填这里的名称即可引用（优先于直接填写的 API 密钥），密钥不再散落各处。

### 11.3 协作（Collaboration）

> 协作是设置里的**一级分组**，下分 **共享 / 协同 / 权限** 三页：先决定**共享什么**，再决定**允许什么**，**协同**管编辑通道。

**共享**（局域网共享 + 共享文件夹）：

*局域网共享（网页端入口）*：

- **操作**：启动 / 停止局域网共享、刷新状态。
- **端口**：静态网页服务端口（默认 **3345**，范围 1024–65535，运行中不可改）。
- **知识库目录**：选择放置 `.kb` 知识库的文件夹，网页端即可看到并使用这些知识库。
- 启动后显示**访问地址**（`http://局域网IP:端口`，列出本机所有网卡 IP，可点击复制），其他设备用浏览器打开即可使用**聊天界面**。
- 网页端的**模型来源与主机自动对齐**：主机在「设置 → 模型 → 来源」里关掉的来源，网页端不再显示；模型探测也由**主机**用主机自己的地址执行，因此主机桌面端能刷出来的模型，网页端（点一下模型下拉即刷新）同样能刷出来。
- ⚠️ 注意：文件浏览、设置等桌面专属功能在远程浏览器中不可用；访客**能用哪些对话模式与工具**由**权限**页决定。

*共享文件夹（远程文件共享，仅桌面版）*：

- **操作**：启动 / 停止共享文件夹服务、刷新状态；**共享目录**选择本机要共享的文件夹。
- **端口**：远程文件服务 HTTP 端口（默认 **3347**，与协同 3346、局域网共享 3345 分开；范围 1024–65535，运行中不可改）。
- **Token**：客户端访问凭据，可重新生成；连接地址中自动带上 token。
- **连接地址**：运行中显示本机各网卡 IP 与链接（`remote-fs://IP:端口?token=…`），复制发给客户端，在**知识管理 → 文件树空白处右键 → 添加远程工作区**粘贴即可只读预览共享目录。
- 客户端可**只读预览**共享目录中的 Markdown / 文本 / **PDF / 图片 / Word** 文件，下载后编辑（详见 **4.7 远程文件共享**）。
- 同一个地址还能当**插件商店 / 技能商店的来源**：在**插件 → 商店**粘贴此链接即可浏览并安装共享目录里的插件与技能（清单由软件实时扫描，无需手写索引文件）。

**协同**（协同文件编辑）：

- **操作**：启动 / 停止协同服务、刷新状态；**服务状态**显示是否运行及当前端口。
- **启用协作**：主开关。关闭后代码编辑器状态栏与白板不再显示协同入口；开启后即可共享文件 / 加入会话。
- **端口**：协同 WS 服务端口（默认 **3346**，与局域网共享 3345 分开；范围 1024–65535，运行中不可改）。
- **连接地址**：运行中显示本机各网卡 IP 与示例地址（`ws://IP:端口/collab/房间号`）。
- **最大成员数**：单个房间最多可同时连接的成员数（2–20）。
- **编辑权限**：**开放**（全员可编辑，默认）/ **批准**（只读成员请求编辑权，主机批准）/ **只读**（仅主机可编辑）。
- **房间 Token**：加入会话的凭据，可重新生成；共享地址中自动带上 token。
- **自动保存间隔**：主机写盘间隔（秒，默认 30s）；**客户端名称**：共享 / 加入时默认显示的昵称（主机显示为**主机**）。

> 💡 协同编辑的使用方法（共享文件、加入会话、权限与保存）详见 **4.6 局域网协同编辑**。

**权限**（局域网访客白名单）：

访客 = 用浏览器打开共享地址的人。网页端没有本地文件与执行能力，**能做什么完全由这一页决定**；默认全只读（等价于改动前的行为）。页面只列控件，各项的详细说明均为**鼠标悬停提示**（鼠标移到标题或控件上即可看到）。

- **对话模式**：开关块（普通 / 知识库 / 智能体，等宽网格，鼠标悬停可见各模式说明）——默认只开 **普通 + 知识库**。勾选 **智能体** 后，网页端可用多步推理 + 调用工具；**循环跑在主机上**（模型、工具白名单、工作区、步数、沙箱全部由主机决定），浏览器只是渲染事件流，拿不到任何额外权限。
- **智能体工具**：逐工具开关（等宽网格，与上方两块左边界对齐；鼠标悬停可见工具名与说明；数据源与**工具 → 管理**、**Agent 预设 → 工具**一致）。带**高危**标记的写入 / 执行 / 外部调用类（写入文件、替换片段、多处替换、执行代码、执行命令、run_code、子代理、MCP 调用、加载技能、导出 Word）**默认关闭**，开启时会二次确认。⚠️ 策略里的**默认集**对访客**永远**等于下面这 6 个只读工具（读取文件 / 列目录 / 搜索文件 / 知识库检索 / 联网搜索 / 抓取网页），不会变成**全部工具**。
- **技能**：没有独立的**技能**模式——技能已并入智能体。勾选工具里的 `skill` 后，访客在网页端输入 `$技能名 任务` 即会加载主机技能并据此执行；技能清单由主机注入提示，访客看不到本机文件。
- **模型来源 / 模型**：指定访客智能体用哪个来源、哪个模型（默认**跟随主机当前来源与当前模型**）。下拉列出**设置 → 模型**里已启用的来源（含每个自定义来源），模型可下拉选已探测到的，也可直接输入模型名；**留空 = 用该来源当前配置的模型**。改完下方会显示**当前生效**的主机模型供核对。模型与密钥始终留在主机，浏览器不接触。
- **可用智能体**：**通用智能体**固定开放（自主规划 + 上方工具白名单）；其余为你在**设置 → 预设**里建好的 Agent 预设，需在这里逐个勾选才会对访客开放（呈现方式为 PTC 的预设不出现在此列表——网页端只能逐个调用工具）。勾选后网页端胶囊（与客户端同一个选择器）即可切换，默认通用智能体。
- **与客户端一致的执行**：访客选中某个智能体后，**系统提示词就是客户端同一套组装结果**（同一角色设定、同一工作方式、同一技能库清单），工作流与客户端完全一致；差异只在安全边界：工具 = 该智能体的工具 ∩ 本页白名单（先裁剪再组装提示词），沙箱级别与工作区围栏始终由本页决定；通用智能体用本页**最大步数**，预设用它自己的循环轮数。
- **最大步数 / 并发上限**：**通用智能体**单轮最大步数（默认 **20**，防死循环；预设按它自己的循环轮数，与客户端一致）与同时允许的访客任务数（默认 **1**，保护主机模型 / GPU）。网页端的普通 / 知识库对话、知识库向量检索与访客智能体**共用**这个额度，超出会提示稍后重试。
- **沙箱级别**：下拉选择 **安全（只读）** / **工作区写入** / **完全访问**——只能比**其他 → 安全策略**、**更严格**，不能更宽松。
- **访问令牌**：下拉选择，默认**不需要令牌**（局域网内直接可访问）；需要时切到**需要令牌**（没有令牌会自动生成），共享地址会带上 `?token=…`，访客首次打开即换发 Cookie，之后无需再输。接口同时接受请求头与 Cookie。
- **访客自带模型**：默认**禁止**（访客使用主机模型，经主机转发；智能体模式下的模型与 Key 始终在主机，浏览器端不接触）。
- ⚠️ 三条边界：① 本页只影响局域网访客，不改变本机任何行为；② 文件的**编辑权限**（开放 / 批准 / 只读）在**协同**页，与本页无关；③ 访客永远不能绕过全局安全策略。
- 💡 改完无需重启共享：每次改动会立即下发给主进程生效；关掉共享服务时，所有访客智能体会话一并结束。

### 11.4 语音（Speech）

**合成（TTS）**：

- **语音类型**：本地语音合成 / IndexTTS2 / Qwen3-TTS。
  - **本地**：浏览器内置合成，可调**语速**（0.5–2）与**音高**（0.5–2）。
  - **IndexTTS2**：服务地址（默认 `http://localhost:9880/`）+ 音色（如 `mazhao`、`zh-CN-YunxiNeural`）+ 语言（如 `zh`、`en`）+ 可选**情感参数**与**权重**（0–1）。
  - **Qwen3-TTS**：服务地址 + 音色 + 语言。
- 可 🔊 **测试语音** / ⏹ **停止语音**。

**输入（ASR）**：

- **识别引擎**：**ONNX Whisper**（本地离线，默认，推荐）/ **Whisper API**（需 API 密钥）/ **Whisper Python**（需安装 openai-whisper 包）/ **Qwen3-ASR**（本地网页服务或 OpenAI 兼容端点）/ **FunASR 流式 Paraformer**（本地实时出字）。
- **识别语言**：中文 / 英语 / 日语 / 韩语 / 法语 / 德语 / 西班牙语 / 俄语 / 自动检测。
- **快捷按键**：点击输入框后按下组合键，即设为本软件全局**按住说话快捷键**（默认 `Ctrl+Shift+Space`，应用在后台也生效），带 ↺ 重置按钮。
- **选项**：连续识别（说话时持续识别）、识别后自动发送。
- **Whisper API** 专属：API 地址（如 `https://api.openai.com/v1/audio/transcriptions`）+ API 密钥 + 模型（如 `whisper-1`）。
- **Qwen3-ASR** 专属：**接口协议**（自动按地址判断 / Gradio 网页服务 / OpenAI 兼容）+ API 地址 + API 密钥 + 模型；网页服务默认 `http://127.0.0.1:7867`（按 `/run` 接口自动上传音频并取回识别文本），另可设**语种选择**（默认**自动识别**）、**单行最大字符数**、**跟随标点断句**与**说话人角色识别**；OpenAI 兼容端点填 `http://localhost:8000/v1/audio/transcriptions`（仅支持整段识别）。
- **Qwen3-ASR（网页服务）识别方式**：**流式（分段准实时）**= 按住说话时一停顿就切段送去识别，文字边说边出（说完一句、停顿后约 0.5~1.5 秒出字，不是逐字上屏）；**整段**= 松手后一次识别。分段参数：**停顿切段**（默认 800ms）、**单段最长**（默认 15 秒，上限 3 分钟，一直不停顿就强切）、**切点重叠**（默认 300ms，避免切在字中间丢音）。
- **ONNX Whisper** 专属：模型文件（选择 `.onnx` 文件，如 `whisper-tiny.onnx`）+ **执行后端**（WASM 兼容性最好 / WebGL GPU 加速）+ **使用本地 WASM 文件**（勾选后离线，从应用目录 `ort-wasm/` 加载；不勾选从 CDN 加载需联网）；下方显示模型加载状态。
- 可 🎤 **按住说话测试**（按住录音，松开识别，显示识别结果 / 失败原因），🗑 清除结果。

### 11.5 工具（Tools）

**管理（工具白名单）**：配置**主页智能体对话 / 通用智能体**执行时的**全局默认工具白名单**，关闭的工具不会被注入给模型（Agent 预设与集群成员用各自的**逐工具列表**，不受此白名单限制）。

- 每个工具一张卡片：图标、名称、代码键名、说明、**沙箱偏好**（只读 / 工作区写入 / 完全访问 / 无限制）、**审批要求**（请求时询问 / 禁止 / 自动）、开关。
- 顶部按钮：✓ **全部启用**、↺ **恢复默认**（恢复为**未配置**= 注册表默认，未来新增工具自动纳入）。
- 白名单语义：未配置 = 全部默认启用；全部关闭 = 模型不调用任何工具；只勾选部分 = 仅启用勾选的工具。
- 内置 18 个工具（**逐工具粒度**）：📂 读取文件 `read_file`、✍️ 写入文件 `write_file`、🩹 替换片段 `replace_in_file`、🧩 多处替换 `multi_replace`、📁 列出目录 `list_dir`、🔎 搜索网页 `web_search`、🌐 获取网页 `web_fetch`、🔍 搜索文件 `search_files`、💻 执行代码 `run_python`、🖥️ 执行命令 `shell`、🗄️ 知识库检索 `kb_search`、🧠 加载技能 `skill`、🤖 子代理 `run_subagent`、📄 导出 Word `export_word`（**默认关闭**）、🔌 MCP 调用 `mcp_call`（**默认关闭**）、❓ 询问用户 `ask_user`、📋 更新计划 `update_plan`、✅ 任务清单 `update_todo`。
- 读取大文件：`read_file` 单次有长度上限（PDF / Word / Excel 约 2 万字符，纯文本约 100KB），超出时返回截断位置与 `nextOffset`，智能体会用 `offset` 自动续读直到读完；也可直接指定 `offset` / `limit` 读取任意字符区间。
- 技能自带资源（如 `regulations/xxx.md`）：`read_file` / `list_dir` / `search_files` 可传 `skill: "技能名"`，路径相对**该技能目录**解析；不带 `skill` 的相对路径一律相对**当前工作区**（工具工作目录不会因执行技能而改变）。
- Agent 预设与集群成员的**工具**页用同一份逐工具列表，可分别为每个预设 / 成员精确勾选（与全局白名单相互独立）。

**MCP**：配置与管理 **MCP 服务器**（Model Context Protocol，让 Agent 调用外部工具/服务）。

- 支持三种传输：**stdio**（本地命令，填 command / args / 环境变量 env JSON）/ **sse**（远程，填 serverUrl / headers JSON）/ **http**（HTTP/Streamable 远程）。
- 每个服务一张卡片：名称、传输徽标、**启用开关**（关闭即断开）、连接状态与工具数量；按钮：展开**工具列表**（工具 chips + 刷新）、**测试连接**（临时连接不缓存）、**连接 / 断开**、**编辑**、**删除**（带确认）。
- 配置项：名称（必填）、传输类型、**调用超时（秒，留空 = 默认 60 秒）**、命令 / 参数 / 环境变量（stdio）或 URL / 请求头（远程）与**自动连接**复选框；改动自动保存，由主进程承载连接。

| 服务 | 提供的能力 |
|---|---|
| **内置浏览器 Agent**（`builtin-browser`） | AI 可控制的真实浏览器窗口（多标签）：导航、新建 / 切换 / 关闭标签、读取正文 / Markdown / HTML、点击、输入、滚动、截图等 `browser_*` 工具 |

| **PostgreSQL 只读查询**（`builtin-postgres`） | 把本地 / 内网 PostgreSQL 库（典型场景：导入 OpenAlex 离线快照等大数据集）以**只读**方式交给 AI 查询（共 7 个函数）：**pg_resolve_author**（**作者消歧**：人名可只给姓或**姓+首字母**，加可选机构参考，一次调用返回候选表 + 机构历史 + 代表作 + 置信分档，无结果返回 No Result；机构名不在库中或给缩写时自动退化为关键词匹配）、**pg_status**（连接与配置自检，报错先调它）、**pg_list_schemas**（schema 清单）、**pg_list_tables**（表 / 视图清单 + 行数估算 + 注释，支持关键字过滤）、**pg_describe_table**（列 / 类型 / 索引 / 表大小）、**pg_sample_rows**（采样看数据形态）、**pg_query**（执行只读 SQL：聚合 / CTE / JOIN / 窗口函数，返回 Markdown 表格）。三层只读保护：SQL 静态校验（仅 SELECT / WITH / TABLE / VALUES / SHOW / EXPLAIN，拒绝多语句与写类关键字）、连接强制只读事务、语句超时（默认 30 秒，可用 `PG_MCP_STATEMENT_TIMEOUT_MS` 调大）；缺省 LIMIT 自动补上；连接后自动把库里唯一的用户 schema（如 `openalex`）设为 `search_path`，SQL 可直接写表名。连接信息在**配置 → 环境变量 env**填写（`PGHOST` / `PGPORT` / `PGDATABASE` / `PGUSER` / `PGPASSWORD`，或单条连接串 `PG_MCP_CONNECTION_STRING`），密码只存本机设置 |
| **插件开发参考**（`builtin-plugin-dev`） | 把官方**插件开发指南**作为 MCP 服务提供，按主题拆成 **6 个短工具**（每次只回几百到三千字，小模型也吃得下）：**plugin_dev_host**（本机插件目录的**绝对路径** / **文件夹命名规则** / 已装插件清单 / 数据该放哪）、**plugin_dev_constraints**（15 条硬性约束，含**只准调用指南列出的宿主 API、两半边不能混用**、**canvas 不认 CSS 变量**、**图表要由数据驱动重画**「`ctx.locale` 的 ref 不能当字符串用」）、**plugin_dev_manifest**（`package.json` 清单字段 + 内置槽位 + 可照抄的清单）、**plugin_dev_api**（宿主 API 速查 + 最小可运行示例全文）、**plugin_dev_faq**（报错对照）、**plugin_dev_templates**（模板目录与安装步骤，正文用 `key` 逐取，如 `{"key":"panel"}`），另有 **plugin_dev_check**（自检：目录名能否作为插件 id、清单 / 入口文件 / 界面半边，用宿主**同一份**校验逻辑，并返回**宿主真实的加载状态与日志**，含界面半边装载失败的原因）——与**插件 → 开发**页同一份内容。**插件开发智能体**默认已绑定本服务；其它智能体 / 工作流 MCP 节点 / 外部 MCP 客户端也能用，写插件时不必再去磁盘上找软件源码 |

- 六个服务都是**主进程内进程**，不依赖外部程序；启动软件 / 进入设置页时自动注入，**默认启用并自动连接**，**不可删除**（但可关闭启用、改名、测试连接、查看函数）。
- 调用方式：通用智能体 / Agent 预设 / 集群成员 / 工作流 MCP 节点都通过 **`mcp_call`** 工具调用。
- **会话式工具怎么用**：Word / Excel 工具先 `open_document` / `open_workbook` 取得 `docId` / `workbookId`，后续调用必须把它原样带上；智能体上下文已**附带各工具的参数签名（必填项有标注）**，缺必填参数会在 `mcp_call` 层直接拦下并提示，参数别名（`query_sheet` → `sheet`、`workbook_id` → `workbookId`、`file_path` → `path` 等）也会自动归一。
- **对外 HTTP 暴露**：打开左下角**内置服务：对外 HTTP 暴露**后，会挂到 `http://127.0.0.1:43112/mcp/builtin-browser`、`/mcp/builtin-office`、`/mcp/builtin-drawio`、`/mcp/builtin-literature`、`/mcp/builtin-postgres`、`/mcp/builtin-plugin-dev`，供 Claude Desktop、Cursor 等外部 MCP 客户端接入；健康检查：`http://127.0.0.1:43112/health`。
- ⚠️ MCP 服务（含六个内置服务）的工具**不出现在工具注册表里**，注册表只列主进程直连工具；MCP 工具必须经 `mcp_call` 调用（需在**工具管理**或预设 / 集群的逐工具列表中启用它）。

**注册表**：只读查看**统一工具注册表**——主进程实际注册的工具（**Agent 循环 / PTC（Code Mode）的 ctx SDK / 工具类工作流节点**（如网络搜索、智能体）经它分发执行；**MCP 服务工具不在此列**——builtin-office / builtin-drawio / 外部服务只在 MCP 目录中，须经 `mcp_call` 调用）。每项显示：工具键名、徽章（有参数 schema = 绿色 / 无 = 橙色）、作用域（scope 或**全局**）、描述（最多三行，悬停查看完整内容）；**不在当前生效工具白名单内的项整体灰化并标已禁用**（白名单 =**设置 → 工具管理**，未配置时按 Agent 循环默认可见集）。右上角显示**已注册（N）· 已禁用（M）**+ 🔄 刷新。仅桌面版可用。

**搜索（联网搜索源）**：配置 `web_search` 工具（智能体 / 批量任务 / 工作流**网络搜索**节点共用）使用的搜索源，改完**立即生效、无需重启**。页面为左右分栏（同**模型**页）：左侧为搜索源列表，右侧为选中源的参数与测试。

- **可同时启用多个源**（左侧每项的开关；至少保留一个）：**列表从上到下就是尝试顺序**，可直接**拖动**任意一项调整位置（回退策略下即优先级）。
- **多源策略**（左侧顶部下拉）：**依次回退** = 按列表顺序逐个尝试，第一个有结果的源胜出；**并行聚合** = 所有启用源同时搜索，结果按 URL 去重合并。左侧左上角的 ↺ 按钮可一键**重置**全部搜索源配置（恢复默认：Bing 单源 + 依次回退 + 8 条结果，并清空已填 API Key，带二次确认）。
- **免 Key（开箱可用）**：**Bing 网页**（默认；隐藏浏览器渲染 + HTML 解析兜底，可在其配置里开启**中文查询改写**把长中文句改写为关键词）、**百度**、**DuckDuckGo**（部分网络环境可能被拦截）。
- **自建实例**：**SearXNG**——填实例地址（需实例 `settings.yml` 开启 JSON 输出）+ 可选启用引擎 / 语言。
- **API Key**：**博查**（国内）、**智谱 Web Search**（可选基础 `search_std` / 高阶 `search_pro`）、**Tavily**、**Brave**——粘贴 Key 即可用；Key 只保存在本机，接口地址可自定义（支持代理 / 自建网关）。
- **自定义（内网）源**：左侧工具栏的 **+** 可添加任意数量的自定义源，专给**局域网内网源**用，类型二选一：
  - **SearXNG 兼容实例**：只填实例地址（如 `192.168.1.10:8080`，可不带 `http://`），需实例 `settings.yml` 开启 JSON 输出；可选启用引擎 / 语言。
  - **HTTP JSON 接口**：填请求地址（内网 wiki / 搜索服务），GET 可用 `{query}` 占位、留空则自动追加 `?q=关键词`；POST 可写请求体模板（同样用 `{query}` 占位）；可填 API Key（自动作为 `Bearer` 发送）与**自定义请求头**（每行一个 `Key: Value`，值里可用 `{key}` 代表 API Key）；还需指定**结果数组路径**（如 `data.list` / `hits.hits`，留空自动识别）与**标题 / 链接 / 摘要字段**（支持点号路径，相对链接会按请求地址补全）。
  - 自定义源与内置源一同**拖动排序、启用、测试**，同样参与回退 / 聚合；右侧标题栏的**删除**可移除单个源，左上角 ↺ **重置**会连同全部自定义源一起清除。
- **全局设置**：**返回条数** 1~20（默认 8）。
- **测试**：每个源可单独**测试**（与启用状态无关），或点**测试全部启用源**、**逐个测试每个已启用源**，结果按源分组直接在下方展开（标题 / 链接 / 摘要 + 耗时与通道），便于排查 Key / 实例地址问题。
- 页内的**官方文档 / 申请入口**与测试结果链接均用**自带浏览器**（浏览器 Agent 窗口）打开：已有窗口时新标签页打开，未打开时直接开窗直达，不会跳系统默认浏览器。
- 抓取具体网页（`web_fetch`）不受搜索源影响；浏览器 / 局域网模式下该页仅做本机记录，实际搜索仍由主机执行。

### 11.6 技能（Skills）

- **管理（技能管理）**：浏览技能文件树并用 Monaco 编辑器编辑技能文件（顶部可在**管理 / 配置**间切换，编辑提示词模板）。技能 = 一个文件夹 + 一个 `SKILL.md` 文件。
- **商店**：从 GitHub 技能源浏览、搜索、**下载**技能到本地。

**一个技能长什么样**：`SKILL.md` 用 YAML 头描述名称与用途（AI 靠 `description` 判断什么时候该用它），正文写操作步骤：

```markdown
---
name: my-skill
description: 描述这个技能做什么、何时使用
version: 1.0.0
emoji: 📄
---

这里写技能的详细操作步骤、示例……
```

> 技能没有**新建**按钮：可以从商店下载、在技能文件夹里手动新建文件夹 + `SKILL.md`，或直接复制别人的技能文件夹进来。

**怎么让 AI 用它**：回到主页，用智能体模式（或任意模式）触发即可——

- **显式**：输入 `$技能名 任务`，如 `$pdf 帮我生成一份 PDF 报告`。
- **隐式**：直接用自然语言描述任务，AI 按技能描述自动匹配。
- 输入 `技能列表` / `/skills` 可查看技能目录，输入 `help 技能名` 查看该技能详情。

### 11.7 智能体（Agent）

**预设（Agent 预设）**：管理可复用的 **Agent 配置模板**（以 `.agent` 文件存储）。

- 左侧列表：🔍 搜索、➕ **新建预设**、🗑 删除；右侧编辑当前预设。列表顶部固定显示八个**内置预设**（通用 / 代码 / 办公 / PTC / 插件开发 / Pi / DSH / Codex 智能体，带 🔒 与**内置**标记，**不可删除**、可编辑）。
- **恢复出厂默认**：内置预设的配置页标签栏最右侧有**恢复默认**（↩）按钮 —— 确认后把该预设的名称 / 模型 / 系统提示 / 工具 / 技能 / MCP / 指令段整体还原成出厂值（用户自建预设没有出厂默认，故不显示该按钮）。
- 配置项：**名称 / 角色 / 系统提示**、**模型**（类型 / 模型 / 温度）、**工具配置**（能力插槽开关，映射到 Agent 循环统一工具注册表：读取文件、写入文件、执行代码、搜索网页、浏览网站、搜索文件、执行命令、知识库检索、技能库、子代理、MCP 控制等）、**技能配置**（勾选该预设可用的技能，默认全选 = 与通用智能体一致）、**知识库配置**（开启**访问知识库**后添加 `.kb` 文件并设置**召回切片数**）、**MCP 配置**（开启**MCP 控制**后选择可用的 MCP 服务）。
- **呈现方式（工具页顶部）**：`逐个调用`（默认）= 每个启用的工具以函数 schema 暴露给模型；`PTC` = 模型只看到 `run_code`，用一段 TypeScript 程序组合调用该预设启用的那些工具（`run_code` 自动启用、不在工具列表中）。它决定**模型看到的形态**，不改变能做什么——呈现按预设固定，同一会话中途切换会让提示词前缀变化。带 PTC 的预设可在聊天 / 工作流智能体节点 / 集群成员 / 批量（脚手架）中直接选用，内置的**PTC 智能体**就是这么配的。
- **循环配置（AgentLoop 提示词）**：在**循环**标签定制该预设运行时的系统提示组装方式，默认**自动组装**（与通用智能体一致，由能力 / 技能 / 知识库自动拼装）：
  - **指令段模式**：切换为**指令段**后，系统提示被拆成多个可排序段落（标题 + 正文），运行时**按顺序合并为一份系统提示**注入模型；每段正文支持 `{{变量}}` 插值，可展开**预览最终提示词**查看合并结果，MCP 服务上下文会自动追加到末尾。
  - **预设模板**：一键套用主流编码 Agent 的提示词结构（借鉴其风格、非逐字）——**Pi**（身份 + 工具 + 简洁响应）、**Codex**（身份 + 计划 + 任务执行 + 最终汇报）、**Copilot**（身份 + 任务 + 技能 + 协作）、**DeepSeek Harness**（身份 + 环境 + 工具 + 规划）；点**清除**可一键清空所有指令段。套用后仍可继续编辑 / 排序 / 删除。
  - **可用变量**：`{{toolUsage}}`（可用工具）· `{{kbHint}}`（知识库能力）· `{{skills}}`（技能库清单）· `{{cwd}}`（工作目录）· `{{model}}`（模型）· `{{provider}}`（来源）。
- **三个「外部 harness 风格」预设**（只借鉴开源项目的提示词结构与工具编排，不依赖外部程序）：
  - **Pi 智能体**：极简编码风格——不做计划模式、不派生子智能体，工具集小而准（读写 / 搜索 / 命令 / 联网 / 技能），先读再写、改动最小、一步做完、验证再交付。
  - **DSH 智能体**：装配式风格——提示词用**指令段**组装（人格段 + 环境 + 项目指令 + 能力行 + 规划委派 + 运行护栏 + 交付），可在预设页增删 / 上下移动各段；带完整开发工具集（含计划 / 清单 / 子智能体）。
  - **Codex 智能体**：终端编码风格——提示词里写明三档沙箱边界（只读安全 / 工作区写入 / 完全访问，与**设置 → 通用 → 其他 → 安全策略**对应）、AGENTS.md 项目约定、补丁式最小改动，以及**给同事交接工作**式的收尾汇报。
- **知识库检索**：预设开启**访问知识库**后，对话中 Agent 会自动调用 `kb_search` 检索关联知识库，并实时显示**参考了 N 个知识片段**的来源。
- 主页 👤 图标可一键以该预设角色对话。

**控制台（智能体控制台）**：执行中心，实时查看所有 Agent 会话与后台任务。

- 左侧**任务列表**：agent 会话 + 后台任务，显示状态图标、类型、进度条；执行中优先排序。空态提示去主页**智能体**模式发消息。
- 右侧**详情**：agent 会话显示状态徽章、T 回合 / S 步、排队输入数、最后错误、**执行计划**、**任务清单**、**执行时间线**（步骤文本 + 可展开的工具调用：参数 / 结果 / 错误）。
- 操作：⏹ **取消当前执行**、🗑 **销毁智能体**、🔄 刷新、回答待处理问题、**转向输入**（steer 引导）、**注入上下文**（inject）。

**日志（会话日志）**：查看 Agent 会话的完整执行日志。

- 顶部**会话下拉**选择会话（显示事件数与最后时间）+ 刷新 / 加载。
- 三个标签页：① **派生消息**（按 user / assistant / tool / system 角色着色，含工具调用名）② **事件流**（seq、类型、时间，点击展开完整 payload）③ **完整性**（seq 是否连续自洽）。
- 支持 **清空全部日志**（带确认，提示不可恢复）。
